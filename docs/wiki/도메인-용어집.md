# 도메인 용어집

코드와 문서에 자주 나오는 업무 용어입니다. 분야별 상세 규칙은 AI 서버의 Tool 문서에 있습니다.

## 판매 방식

| 용어 | 뜻 |
|---|---|
| 사입 | 셀러가 해외에서 상품을 직접 사서 들여온 뒤 국내에서 파는 방식. 셀러가 수입자이므로 인증 의무를 직접 집니다 |
| 구매대행 | 국내 소비자의 주문을 받아 해외 판매자에게서 대신 사 주는 방식. 일부 품목은 인증 특례가 있습니다 |
| 셀러 | 스마트스토어·쿠팡 등에 상품을 올려 파는 판매자. 이 서비스의 사용자입니다 |

## 인증·규제

| 용어 | 뜻 | 관련 Tool |
|---|---|---|
| 세관장확인 | 수입 통관 때 세관장이 다른 법령의 요건(인증·허가)을 갖췄는지 확인하는 제도. HS 코드로 대상이 정해집니다 | 통관 |
| HS 코드 | 국제 품목 분류 번호. 같은 상품이라도 HS 코드에 따라 통관 요건이 달라집니다 | 통관 |
| 품목분류 결정사례 | 관세청이 특정 상품의 HS 코드를 정한 사례. 비슷한 상품의 HS 코드를 찾는 근거로 씁니다 | 통관 |
| KC 인증 | 국내 안전 기준을 통과했다는 표시. 전기용품, 생활용품, 어린이제품, 전파 기자재 등에 따로 있습니다 | 전기·어린이·전파 |
| 안전인증 / 안전확인 / 공급자적합성확인 | KC 인증의 세 등급. 위험도가 높을수록 안전인증, 낮을수록 공급자적합성확인입니다 | 전기·어린이 |
| 전파 적합성평가 | 전파를 쓰는 기기(무선·블루투스 등)의 인증. 적합인증, 적합등록, 잠정인증이 있습니다 | 전파 |
| 어린이제품 | 만 13세 이하 어린이가 쓰는 제품. 별도 안전 기준이 적용됩니다 | 어린이 |
| 표시·광고 | 상세페이지 문구가 의료·화장품 효능 등 실증이 필요한 주장을 하는지 | 표시·광고 |

## 법령 원문

| 용어 | 뜻 |
|---|---|
| 별표 | 법령·고시에 붙은 표. 대상 품목과 인증 종류가 대부분 별표에 있어서 판단의 핵심 근거가 됩니다 |
| 고시 | 행정기관이 법령을 집행하려고 정한 세부 기준. 별표가 주로 고시에 붙어 있습니다 |
| 법제처 API | 법령·고시 원문과 별표를 받아 오는 공공 API |

## 서비스 용어

| 용어 | 코드 이름 | 뜻 |
|---|---|---|
| 진단서 | `Diagnoses` | 한 번에 요청한 상품 묶음(최대 10개)의 진단 결과 |
| 상품 | `Product` | 진단 대상 상품 하나. AI 진단 세션 하나와 짝을 이룹니다 |
| 규제 Tool | `ToolName` | 분야별 판단 모듈. 통관(`CUSTOMS`), 전파(`RADIO`), 식품·의약품(`FOOD_DRUG`), 전기용품(`ELECTRICAL`), 어린이제품(`CHILDREN`), 표시·광고(`LABEL_AD`) |
| 판단 | `Determination` | 해당(`REQUIRED`), 해당 가능(`POSSIBLY_REQUIRED`), 해당 없음(`NOT_REQUIRED`), 정보 부족(`INSUFFICIENT_INFORMATION`), 적용 안 됨(`NOT_APPLICABLE`) |
| 결과 상태 | `ResultStatus` | 구매대행 가능(`PURCHASING_AGENT_ALLOWED`), 사입 시 인증 필요(`DIRECT_IMPORT_CERTIFICATION_REQUIRED`), 재확인 필요(`RECHECK_REQUIRED`) |
| 진행 상태 | `ProcessingStatus` | 대기(`PENDING`), 진행 중(`IN_PROGRESS`), 답변 필요(`AWAITING_INPUT`), 완료(`COMPLETED`), 실패(`FAILED`) |
| runId | `runId` | AI가 진단을 한 번 실행할 때마다 붙이는 ID. 재진단하면 새로 발급됩니다 |
