## 역할 나눔

**"이게 화장품인가" 같은 해당 여부는 모델이 원문 근거로 판단하고, 코드는 그 판단에 법 조문·할 일을 붙인다.**

| 단계 | 담당 | 내용 |
|---|---|---|
| ① 조건 추출 | 모델 | 필수 판단 3개(음식 접촉·먹는 것·바르는 것: 예/아니오/모름 + 원문 근거), 원문 인용 조건(제품 종류·재질·용도·효능 문구·피부·모발 효과 문구·성분), 의료기기 품목 명칭, 기능성화장품 범위 번호 |
| ② 영역별 규칙 | 코드 | 판단 "예" + 원문 근거 대조가 되면 그 영역의 법 조문·할 일을 붙임. 기능성 번호는 시행규칙 제2조에 실제 있는 호만, 성분은 금지 원료와 이름 대조 |
| ③ 의료기기 조회 | 코드 | 품목·등급 별표 1(2,168개)에서 비슷한 품목 8개 |
| ④ 품목 선택 | 모델 | 후보 중 맞는 품목 최대 3개 + 이유. 등급·인용문은 코드가 품목 행으로 붙임 |
| ⑤ 결과 조립 | 코드 | 근거·판매 방식별 할 일·질문 |

- 세 판단은 **필수 출력**이다. 선택 칸으로 두면 gpt-4.1-mini가 "섭취" 같은 근거가 있어도 판단을 건너뛰는 일이 잦았다(같은 입력 2회 중 1회, 실측).
- 필수로 바꾼 뒤에는 저주파 패드·팔찌를 "바르는 것"으로 답하는 반대 오류가 나와, "몸에 붙이거나 차는 기구·패드·장신구는 아니오"를 명시했다.
- 바르는 상품의 효과 문구는 어느 효능 칸에 들어왔든 기능성 대응 근거로 쓴다(모델이 "미백"을 질병 효능 칸에 넣는 일이 있다).

## 영역별 판단

| 영역 | 조건 | 판단 | 근거 |
|---|---|---|---|
| 식품용 기구·용기 | 음식 접촉 "예" | `POSSIBLY_REQUIRED` "식품용 기구·용기 후보 — 수입신고 대상" | 식품위생법 제2조 4·5호, 수입식품법 제14조 ①·제15조 ①·제20조 ①, 시행령 제2조 |
| 식품·건강기능식품 | 먹는 것 "예" | `POSSIBLY_REQUIRED` "식품·건강기능식품 후보 — 수입신고 대상". 질병·신체 효능 문구가 있으면 건강기능식품 확인 안내 추가 | 식품위생법 제2조 1호, 수입식품법 제2조 1호(수입식품등에 건강기능식품 포함)·제14·15·20조, 건강기능식품법 제3조 |
| 화장품 | 바르는 것 "예" | `POSSIBLY_REQUIRED` "화장품 후보 — 화장품책임판매업 등록 대상" | 화장품법 제2조 1호·11호(수입대행형 거래 알선 포함), 제3조 ①~③ |
| 기능성화장품 | 바르는 상품 + 효과 문구 + 시행규칙 제2조에 있는 호 | `POSSIBLY_REQUIRED` "기능성화장품 후보 — 시행규칙 제2조 제N호" | 화장품법 제2조 2호, 시행규칙 제2조 해당 호, 제4조 ①, 제15조 1호 |
| 사용할 수 없는 원료 | 바르는 상품의 성분명이 별표 1 원료명·화학물질명과 같음 | `POSSIBLY_REQUIRED`, **risk HIGH** "사용할 수 없는 원료 포함 가능성 — {원료}" | 화장품법 제8조 ①·제15조 5호, 화장품 안전기준 고시 제3조·별표 1 행 |
| 의료기기 | 먹거나 바르는 상품이 아니고, 효능 문구가 있거나 품목 명칭이 나옴 | 품목마다 `POSSIBLY_REQUIRED` "의료기기 후보 — {품목명} ({등급}등급)" | 의료기기법 제2조 ①·제15조·제17조·제26조 ①, 시행규칙 제32조 ①, 품목·등급 고시 별표 1 |
| 효능 문구 + 품목 미확인 | 위 의료기기 경로에서 품목을 못 정함 | `INSUFFICIENT_INFORMATION`(MEDIUM), 오인 표시·광고 금지 안내 | 의료기기법 제2조 ①·제26조 ⑦ |
| 근거 없음 | 어느 영역에도 판단 근거가 없음 | `INSUFFICIENT_INFORMATION` "비대상 판단이 아닙니다" | — |

- 한 상품이 여러 영역에 함께 해당할 수 있다(예: 체온 측정 젖병 → 식품용 기구 + 의료기기).
- 먹거나 바르는 상품의 질병·신체 효능 문구는 의약품 오인 문제라 의료기기 품목으로 보지 않고, 표시·광고 Tool과 함께 보라고 남긴다.
- **금지 원료 대조는 글자 대조다.** "및 그 염류/화합물"을 뗀 이름과 화학물질명 칸까지 보지만, 영문명(INCI)·이명으로 적힌 원료는 찾지 못한다.
  일치하지 않아도 "안전하다는 뜻은 아님"을 가정에 남긴다. 성분 정보가 없으면 "대조하지 못함"을 남긴다.
- 사용상의 제한이 필요한 원료(별표 2, 보존제·자외선 차단제 함량 기준)는 다루지 않는다.

## 판매 방식별 할 일 (모두 조건부)

| 영역 | 사입·수입 | 구매대행 |
|---|---|---|
| 식품용 기구·식품 | 수입·판매업 영업등록 후 판매 목적 수입마다 수입신고 | 인터넷 구매 대행업 영업등록, 구매대행 수입분의 수입신고 대상 여부 확인 필요 |
| 건강기능식품 표방 | 기능성 원료로 만든 건강기능식품이어야 함, 일반 식품이면 표방 문구는 표시·광고 Tool과 함께 확인 | 같음 |
| 화장품 | 화장품책임판매업 등록, 책임판매관리자·품질관리 기준 | 수입대행형 거래 알선도 책임판매업이라 등록 필요(화장품법 제2조 11호) |
| 기능성화장품 | 품목별 심사 또는 보고서 제출, 없으면 판매·수입대행 알선 금지(제15조 1호) | 같음 |
| 금지 원료 | 판매·수입대행 알선·진열 금지(제15조 5호), 전성분 확인 | 같음 |
| 의료기기 | 수입업허가·품목 수입허가 등, 판매업신고, 허가 없는 의료기기 판매·진열 금지 | 자가 사용용 수입은 허가 면제될 수 있으나 허가 없는 의료기기 판매·진열은 금지, 확인 필요 |

- 판단마다 `requirements`에 그 판단의 할 일을 넣는다(재실행에서 판단이 빠지면 ToolExecutor가 그 할 일만 지운다).
- 질문은 판단을 바꾸는 것만: 세 판단의 근거가 엇갈릴 때, 추출 단계만 음식 접촉으로 보고 원문 근거가 없을 때, 의료기기 품목 확정에 필요한 용도.

## 근거 문서 (법제처, 기준일별 캐시)

식품위생법, 수입식품안전관리 특별법·시행령, 건강기능식품에 관한 법률, 화장품법·시행규칙, 의료기기법·시행규칙,
「의료기기 품목 및 품목별 등급에 관한 규정」(별표 1), 「화장품 안전기준 등에 관한 규정」(제3조·별표 1). 10개 문서, 하루 한 번 조회.

- 조문 전체가 아니라 판단에 쓰는 항·호만 잘라 인용한다. 잘라 낼 문구가 없으면(개정으로 바뀐 경우 등) 근거로 쓰지 않는다.
- 화장품법 시행령은 법제처 검색 결과와 본문의 시행일이 달라(검색 2026-04-02, 본문 2026-03-10) 공용 버전 검증이 근거로 쓰지 않는다.
  같은 내용(수입대행형 거래 알선 = 책임판매업)이 화장품법 제2조 제11호에 있어 법 조문을 쓴다.
- `기구 및 용기·포장의 기준 및 규격` 고시는 법제처 API가 본문을 주지 않아 재질별 기준은 다루지 않는다.

## 결과 형식

- `FoodDrugAssessment`: `regulatory_categories`(식품용 기구·용기 / 식품·건강기능식품 / 화장품 / 기능성화장품 / 의료기기),
  `detected_claims`(효능·효과 문구), `ingredients_or_materials`(재질·성분), `applicable_requirements`(근거 법령), `regulated=None`.
- `query`: `food_contact`·`edible`·`skin_applied`(판단 상태), `health_claims`, `functional_types`, `banned_ingredients`,
  `device_terms`, `candidate_items`, `selected_items`, `categories`, `documents`, 버린 수.
- 모델 호출은 공통 `ToolStep`. 사용량 이름은 `food-drug-facts`, `food-drug-review`. 모델·법령 조회 오류는 `FoodDrugToolError`.

## 검증

```bash
python -m pytest tests/tools/food_drug tests/tools/test_registry.py -q
```

- 법제처는 실제 응답 픽스처, 모델은 Fake. 영역마다 대표 결과를 실제 `VerificationAgent().verify_rules()`에 넣어 이슈가 없는지 확인한다.

## 평가 (2026-10-15, gpt-4.1-mini, 1회)

`python -m app.eval.food_drug_runner --eval tests/eval_truth_food_drug/holdout.json`

| | 식품용 기구·의료기기만 (16개, 첫 실행) | 영역 확장 후 (24개) |
|---|---|---|
| 분류 정답 | 15/16 | 23/24 |
| 의료기기 품목 정답 | 4/6 | 5/6 |

- 확장 후 오답: 새치 염색약의 기능성(시행규칙 제2조 제6호 모발 색상 변화)을 대응하지 못함. 온열 찜질기는 예상과 다른 품목.
- 프롬프트는 내장 상품(실행 스크립트 샘플)으로만 고쳤고 평가셋을 보고 고치지 않았다. 다만 f01~f16은 확장 전에 한 번 실행했던 셋이다.
- 예상 답은 사람 검토 전이다. 반복 실행(--runs 3)으로 흔들림을 따로 재야 한다.

## 남은 작업

- 사용상의 제한이 필요한 원료(별표 2), 영문 INCI명·이명 대조(DB `cosmetic_ingredients` 또는 식약처 원료 API)
- 건강기능식품 인정 기능성 원료 대조, 축산물·수산물 등 수입식품 세부 분류
- 기구 재질별 기준·규격, 의료기기 등급별 허가·인증·신고 구분, 자가진단용 의료기기의 판매업신고 예외(법 제17조 ② 4호)
- 판매 방식(구매대행/사입)을 진단 입력으로 받는 것은 BE·FE와 합의할 사항이다.
