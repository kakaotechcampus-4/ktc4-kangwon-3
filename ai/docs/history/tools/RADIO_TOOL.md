# RADIO_TOOL 변경 이력

[RADIO_TOOL.md](../../current/tools/RADIO_TOOL.md)의 변경 경위를 최신순으로 기록한다. 아래 인용은 재작성 전 문서(develop c57f1c29)의 문장을 수정 없이 옮긴 것이며, 괄호 안 줄 번호는 해당 문서 기준이다.

## #823 문서 재작성 (2026-11-11)

- 본문을 현재 동작만 기술하는 형식으로 재작성하였다. 공용 설명은 [TOOL_COMMON.md](../../current/tools/TOOL_COMMON.md)로, 경위·측정·남은 작업은 이 파일로 이동하였다.
- 코드와 일치하지 않던 내용을 수정하였다.
  - 법제처 API로 직접 조회한다고 기술하였으나, DB 캐시를 우선 조회한다(52줄).
  - DB 조회 객체의 칸 정의 문서("어린이·전파 품목표 칸 정의")를 참조하였으나, 저장소에 해당 문서가 없다(59줄).
  - 구매대행 안내를 개인 사용 반입 면제 목을 찾은 경우에만 생성한다고 기술하였으나, 면제 목을 유일하게 찾지 못하면 근거 전체를 확인할 수 없는 것으로 처리하여 기자재를 대조하지 않는다. 그러므로 후보 판단이 생성되면 구매대행 안내가 항상 포함된다(64줄).
  - Tool 실행기 연결을 남은 작업으로 기술하였으나, 이미 연결되어 있다(79줄).
  - 테스트 실행 명령을 `uv run pytest`로 기술하였으나, 저장소에는 uv 설정이 없다(86줄).
- 문서에 없던 동작(분류명 목록의 추출 입력, 조회어 구성, 무선 기능·주파수 없음 가정, 선택 모델 입력 구성, 판단 요약·가정·할 일 문구, 평가유형이 여러 개인 행의 처리, 근거 확인 실패 조건, 원문이 없을 때의 질문)을 추가하였다.
