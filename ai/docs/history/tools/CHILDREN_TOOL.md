## #823 문서 재작성 (2026-11-11)

- 본문을 현재 동작만 기술하는 형식으로 재작성하였다. 공용 설명은 [TOOL_COMMON.md](../../current/tools/TOOL_COMMON.md)로, 경위·측정·남은 작업은 이 파일로 이동하였다.
- 코드와 일치하지 않던 내용을 수정하였다.
  - 공용 모듈에 모델 호출 단계(`agent.py`)가 있다고 기술하였으나, 해당 파일은 없으며 모델 호출 단계는 `app/tools/base/steps.py`에 있다(11줄).
  - 전기 Tool의 법제처 조회 코드를 후속 작업에서 공용 모듈로 통합한다고 기술하였으나, 이미 통합되어 있다(17줄).
  - 법제처 API로 직접 조회한다고 기술하였으나, DB 캐시를 우선 조회한다(57줄).
  - 표 읽기를 DB 적재 전까지 사용하는 임시 경로로 기술하였으나, 현재 유일한 조회 경로이며 DB 조회 구현은 없다(62줄).
  - 순위 밖 품목만 적용범위를 줄여 입력한다고 기술하였으나, 순위 안 품목도 1500자로 잘라 입력한다(79줄).
  - Tool 실행기 연결을 남은 작업으로 기술하였으나, 이미 연결되어 있다(91줄).
  - 테스트 실행 명령을 `uv run pytest`로 기술하였으나, 저장소에는 uv 설정이 없다(98줄).
- 문서에 없던 동작(품목명·제외 물품 목록의 추출 입력, 조회어 구성, 숫자 중간부터 잘린 연령 값 제외, 금지 문구 인용 처리, 번역 연령 표기, 낱말 판정, 제외 물품 이름 목록, 판단별 화면 문구, 가정 문장, 할 일 문구, 질문 범위, 원문이 없을 때의 질문)을 추가하였다.

리뷰 반영 (76-82줄)

> ## 리뷰 반영 (#313)
>
> - **후보 수:** 맞는 품목이 없을 때 공급자적합성확인으로 낮춰 안내하므로, 조회 상위 6개에 안전인증·안전확인 품목 21개를 모두 더해 모델에 준다.
>   순위 밖 품목은 적용범위를 300자만 넣는다(전문을 모두 넣으면 품목 선택 입력이 약 1,900 → 8,500~9,200토큰, 300자로 줄여 5,500~6,000토큰. 실측).
>   후보가 늘어 모델이 덜 맞는 품목을 함께 고르는 일이 있다(예: 휴대용 유모차에 자동차용 어린이 보호장치). 평가셋으로 정밀도를 따로 봐야 한다.
> - **포함 문구:** "어린이용 안경테(선글라스를 포함한다)"처럼 품목명에 붙은 포함 문구는 조회어 목록·순위에서 뗀다(`short_name`, `includes`). 근거 원문과 판단 제목은 원문 이름 그대로.
> - **영문 연령:** 해외 직구 표기를 읽는다. 한 글자 `M`·`Y`는 `+`나 끝이 붙을 때만 단위로 본다("5M 케이블"·"3M" 상표 방지). 영문 금지 문구(`not for … under N`)는 그 연령 이상으로 읽는다.
