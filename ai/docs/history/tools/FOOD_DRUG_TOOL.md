# FOOD_DRUG_TOOL 변경 이력

[FOOD_DRUG_TOOL.md](../../current/tools/FOOD_DRUG_TOOL.md)의 변경 경위를 최신순으로 기록한다. 아래 인용은 재작성 전 문서(develop c57f1c29)의 문장을 수정 없이 옮긴 것이며, 괄호 안 줄 번호는 해당 문서 기준이다.

## #823 문서 재작성 (2026-11-11)

- 본문을 현재 동작만 기술하는 형식으로 재작성하였다. 공용 설명은 [TOOL_COMMON.md](../../current/tools/TOOL_COMMON.md)로, 경위·측정·남은 작업은 이 파일로 이동하였다.
- 코드와 일치하지 않던 내용을 수정하였다.
  - 사용할 수 없는 원료 판단을 항상 위험도 HIGH로 기술하였으나, 원료명에 사용 조건이 기재된 행(조건부 금지 원료)은 제목이 "사용할 수 없는 원료 해당 여부 확인 — {원료}"이고 위험도는 MEDIUM이다(44줄).
  - 건강기능식품 확인 안내의 조건을 질병·신체 효능 문구로만 기술하였으나, 먹는 상품은 피부·모발 효과 문구도 함께 확인한다(41줄).
  - 기능성화장품 근거를 화장품법 제15조 제1호로 기술하였으나, 실제 인용 범위는 제15조 제1호-제5호다(43줄).
  - 질문 조건을 3가지로 기술하였으나, 모델이 "예"로 판단하였으나 인용이 원문과 일치하지 않아 제외된 판단도 질문한다(67줄).
  - 근거 문서를 하루 한 번 조회한다고 기술하였으나, 기준일별로 6시간 캐시하며 법제처 응답은 DB 캐시를 우선 조회한다(72줄).
  - 화장품법 시행령을 근거로 사용하지 않는 이유를 공용 버전 검증으로 기술하였으나, 공용 검증은 시행일 차이를 로그로만 기록한다. 시행령은 근거 문서 목록에 포함되어 있지 않다(75줄).
  - 남은 작업에 존재하지 않는 DB 테이블(`cosmetic_ingredients`)이 기재되어 있었다(110줄).
- 문서에 없던 동작(근거 조회를 조건 추출보다 먼저 수행, 판단 칸 상태 결정, 의료기기 조회 순서와 조회어, 영역별 고정 가정, 품목 미대응 시 처리, 근거 조문 절단 규칙, 원문이 없을 때의 처리)을 추가하였다.

## #374 식약 Tool 단독 구현 (2026-10-26)

필수 판단 3개를 필수 출력으로 정한 경위 (32-33줄)

> - 세 판단은 **필수 출력**이다. 선택 칸으로 두면 gpt-4.1-mini가 "섭취" 같은 근거가 있어도 판단을 건너뛰는 일이 잦았다(같은 입력 2회 중 1회, 실측).
> - 필수로 바꾼 뒤에는 저주파 패드·팔찌를 "바르는 것"으로 답하는 반대 오류가 나와, "몸에 붙이거나 차는 기구·패드·장신구는 아니오"를 명시했다.

화장품법 시행령을 근거로 사용하지 않게 된 경위 (75-76줄)

> - 화장품법 시행령은 법제처 검색 결과와 본문의 시행일이 달라(검색 2026-04-02, 본문 2026-03-10) 공용 버전 검증이 근거로 쓰지 않는다.
>   같은 내용(수입대행형 거래 알선 = 책임판매업)이 화장품법 제2조 제11호에 있어 법 조문을 쓴다.

기구 기준·규격 고시를 다루지 않는 이유 (77줄)

> - `기구 및 용기·포장의 기준 및 규격` 고시는 법제처 API가 본문을 주지 않아 재질별 기준은 다루지 않는다.
