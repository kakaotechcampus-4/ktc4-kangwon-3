# 어린이제품 안전 Tool

어린이제품 안전 특별법의 품목표에서 상품에 해당할 가능성이 있는 품목을 찾고, 제도(안전인증·안전확인·공급자적합성확인)와 판매 전 할 일을 제시하는 Tool이다. 실행 틀, 원문 대조, 질문, 법령 조회 등 공용 동작은 [TOOL_COMMON.md](TOOL_COMMON.md)에서 설명한다.

## 1. 개요

- 법령 원문 전체를 모델에 입력하지 않는다. 시행규칙 별표 1-3 품목표에서 상품과 유사한 행을 조회하고, 그중 해당하는 행을 모델이 선택한다.
- 판정은 `POSSIBLY_REQUIRED`(후보) 또는 `INSUFFICIENT_INFORMATION`(정보 부족)만 사용한다. 확정 판정(`REQUIRED`·`NOT_REQUIRED`)은 생성하지 않는다.
- 해당하는 품목 행이 없어도 바로 정보 부족으로 처리하지 않는다. 만 13세 이하 대상이 확인된 어린이제품은 안전인증·안전확인 품목이 아니어도 공급자적합성확인대상이다(법 제2조 제12호).
- 어린이제품법·시행규칙에는 구매대행 특례 조문이 없으므로 판매 방식(구매대행·사입)을 구분하지 않고 안내한다.

| 역할 | 담당 |
|---|---|
| 상품 조건 값과 원문 인용 추출, 조회어 선택 | 모델 |
| 인용 대조, 연령 판정, 제외 물품 값 검사, 품목 조회, 근거 첨부 | 코드 |
| 후보 행 중 상품에 해당하는 행 선택과 선택 이유 | 모델 |

## 2. 입력

### 조건 필드

| 필드 | 표시 이름 | 비고 |
|---|---|---|
| `product_type` | 제품 종류 | 필수. 확인되지 않으면 품목을 선택하지 않음 |
| `target_age` | 사용 대상 연령 | 4.1의 연령 판정에 사용 |
| `intended_use` | 제품 용도 | 조회어에 사용 |
| `material` | 재질 | |
| `excluded_kind` | 제외 물품 해당 여부 | 정해진 이름 7개 중 하나만 유지 (4.3) |

- 조건 추출 모델 입력에 품목명 목록(시행규칙 품목명과 운용요령 품목명, 포함 문구를 제거한 이름)과 제외 물품 이름 목록을 포함한다. 모델은 품목명 목록 안에서 조회어(`search_terms`, 최대 3개)를 선택한다. 상품별 동의어 사전은 사용하지 않는다.
- 품목명 목록을 조회할 수 없으면 목록 없이 조건을 추출한다.
- 제외 물품은 값이 정해진 이름이므로 인용만 원문과 대조하고, 값은 이름 목록과 대조한다(공백·가운뎃점 차이 무시).
- 연령 값이 인용 안에서 숫자 중간부터 시작하면 제외한다. 예: 인용 "13세 이상"에서 값 "3세".
- 인용할 원문이 없으면 제품 종류와 사용 대상 연령을 질문한다.

## 3. 처리 흐름

```text
① 품목명 목록 조회 (코드)  조건 추출 모델에 입력할 품목명
② 조건 추출 (모델)         제품 종류·연령·용도·재질·제외 물품 + 원문 인용, 조회어
③ 연령 판정 (코드)         만 13세 이하 포함 여부, 연령 충돌
④ 품목 조회 (코드)         유사한 상위 6개 + 안전인증·안전확인 품목 전체
⑤ 코드 규칙                제외 물품, 연령 미포함
⑥ 품목 선택 (모델)         후보 행 중 해당하는 행 최대 3개 + 선택 이유
⑦ 결과 조립 (코드)         행 원문 근거, 해당 행이 없으면 공급자적합성확인 기본 후보, 할 일
```

### 3.1 품목 조회

- 조회어는 모델 조회어, 제품 종류·제품 용도 값, 상품명·카테고리·용도를 합하여 구성한다.
- 순위는 품목명(시행규칙·운용요령, 포함 문구 제거)과 조회어의 글자 2개 단위 유사도로 산정하며, 품목명이 조회어에 그대로 포함되면 가산한다(`common.ranking.rank_rows`).
- 상위 6개에 안전인증·안전확인 품목 전체를 추가하여 선택 모델에 입력한다. 해당 행이 없을 때 공급자적합성확인으로 안내하므로, 두 제도의 품목이 조회 순위에서 누락된 채 낮은 제도로 안내되는 것을 방지하기 위함이다.
- 선택 모델에는 적용범위를 잘라 입력한다. 순위 안 품목은 1500자, 순위 밖에서 추가한 품목은 300자다. 근거에는 원문 전체를 첨부한다.
- 제품 종류가 없거나, 연령 미포함이거나, 제외 물품이 확인되면 품목 조회 없이 근거 문서만 조회한다.
- 근거 문서를 확인할 수 없으면 "법령 품목표의 시행 버전·본문을 확인하지 못해 품목을 대조하지 않았습니다." 가정을 기록하고 정보 부족으로 종료한다.

## 4. 판정 규칙

### 4.1 연령

법 제2조 제1호의 "만 13세 이하"를 포함하는지 판정한다. 연령 표기를 개월 범위로 해석한다.

| 표기 | 해석 |
|---|---|
| `만 3세 이상`, `36개월 미만`, `3~7세`, `6개월~3세`, `8+` | 개월 범위 |
| "36M+", "24 months", "3-12years", "3 yrs", "and up", "under 3 years" | 영문 표기. 한 글자 `M`·`Y`는 뒤에 `+`나 끝이 올 때만 단위로 인정 ("5M 케이블", "3M" 상표 제외) |
| "3-8 년" | 기계 번역 표기. 세로 해석. "2015년생", "2024년도", "연식", "년형"은 연령으로 해석하지 않음 |
| "N세 이하" | N세 11개월까지 포함 |
| "N세 미만 사용 금지", "not for … under N" | N세 이상으로 해석. "미만"이 포함된 표기를 찾을 때까지 탐색 |
| 그 밖의 금지 문구 | 해석하지 않음 |
| "3세트", "100+" | 연령이 아님 |

- 하한이 만 13세 이하이거나 하한이 없으면 포함, 하한이 만 13세를 초과하면 미포함, 해석할 수 없으면 미정이다.
- 숫자가 없으면 낱말로 판정한다. 영아·유아·아동·어린이·키즈·유치원·초등·신생아·아기가 있으면 포함(성인·어린이 겸용 포함), 성인·어른만 있으면 미포함이다.
- 인용에 금지 문구가 있으나 값에 없으면 인용 전체로 해석한다. 값만 해석하면 금지 문구가 누락되어 판정이 반대가 되기 때문이다.
- 연령 조건이 없으면, 추출 단계의 사용 연령(`product.target_age`)이 상품 원문에 그대로 있을 때 그 값을 사용한다(`query.age_source`).

### 4.2 연령 충돌

- 여러 연령 표기의 판정이 서로 다르면 충돌로 판정하고 연령을 질문한다.
- 추출 단계가 어린이 대상(`product.for_children`)으로 판단하였으나 표시 연령이 미포함이면, 미포함으로 단정하지 않고 충돌로 처리한다. "추출 단계는 만 13세 이하 대상으로 보았으나 표시 연령은 이를 포함하지 않아 어린이제품 해당 여부를 정하지 않았습니다." 가정을 기록한다.
- 충돌이 있으면 "사용 대상 연령 정보가 서로 달라 어린이제품 해당 여부를 정하지 않았습니다." 가정을 기록한다.
- 재질·용도·제품 종류는 값이 여러 개여도 정상으로 보고 모두 사용한다. 제품 종류는 모두 조회어로 사용한다.

### 4.3 제외 물품

법 제2조 제1호 단서는 다음 물품을 어린이제품에서 제외한다: 의약품, 의약외품, 의료기기, 화장품, 식품용 기구, 식품 용기·포장, 테마파크시설.

- 제외 물품 조건이 확인되면 어린이제품 후보를 생성하지 않고 제외 물품 판단만 생성한다. 이 경우 연령은 질문하지 않는다.

### 4.4 선택과 기본 후보

- 선택은 공용 후보 선택 대조를 거친다([TOOL_COMMON.md](TOOL_COMMON.md) 5장). 대조되지 않은 선택은 "후보 행과 대조되지 않은 선택 N개를 제외했습니다." 가정으로 기록한다.
- 해당하는 행이 없을 때의 처리:

| 조건 | 처리 |
|---|---|
| 연령 포함 확인, 제외한 선택 없음 | 공급자적합성확인 기본 후보 (`query.fallback`) |
| 제외한 선택 있음 | 정보 부족. "품목 선택 결과를 원문·후보와 대조하지 못해 품목을 정하지 않았습니다. 안전인증·안전확인 품목일 수 있어 공급자적합성확인으로 낮춰 안내하지 않았습니다." |
| 그 밖의 경우 (연령 미정 등) | 정보 부족. "후보 품목 중 맞는 것을 고르지 못했습니다. 비대상 판단이 아닙니다. 만 13세 이하 대상이면 최소한 공급자적합성확인대상입니다(법 제2조 제12호)." |

## 5. 화면 문구

### 판단

| 경우 | 제목 | 판정·위험도 |
|---|---|---|
| 선택한 행 | {제도}대상 어린이제품 후보 — {품목} | `POSSIBLY_REQUIRED`·`MEDIUM` |
| 기본 후보 | 공급자적합성확인대상 어린이제품 후보 — 개별 안전기준이 없는 품목 | `POSSIBLY_REQUIRED`·`MEDIUM` |
| 제외 물품 | 어린이제품 해당 여부 — 제외 물품 가능성 | `INSUFFICIENT_INFORMATION`·`UNKNOWN` |
| 연령 미포함 | 어린이제품 해당 여부 — 사용 연령 | `INSUFFICIENT_INFORMATION`·`UNKNOWN` |
| 정보 부족 | 어린이제품 안전관리 대상 판정 | `INSUFFICIENT_INFORMATION`·`UNKNOWN` |

| 경우 | 요약 |
|---|---|
| 선택한 행 | "이 품목으로 분류되면 {제도}대상 어린이제품일 가능성이 있습니다(확정 아님)." + "적용 안전기준: …". 연령 미정이면 "사용 대상 연령을 확인하지 못했습니다. 만 13세 이하 대상일 때 적용됩니다."를 덧붙임 |
| 기본 후보 | "안전인증·안전확인 품목에 맞는 것을 찾지 못했습니다. 만 13세 이하 대상 어린이제품이면 공급자적합성확인대상이고 어린이제품 공통안전기준이 적용될 가능성이 있습니다. 확정이 아닙니다." |
| 제외 물품 | "어린이제품법 제2조 제1호 단서의 제외 물품(…)일 가능성이 있습니다. 해당하면 어린이제품 안전관리 대상이 아니라 식약 등 다른 법의 검토가 필요합니다. 확정이 아닙니다." |
| 연령 미포함 | "표시된 사용 연령이 만 13세 이하를 포함하지 않아 어린이제품이 아닐 가능성이 있습니다. 확정이 아닙니다." |
| 정보 부족 | "상품 설명에서 사용 연령이나 해당하는 품목을 찾지 못해 어린이제품 안전관리 대상인지 판단하지 못했습니다." |

- 선택한 행의 판단 근거는 선택 모델이 작성한 선택 이유다.
- 공개 결과에는 가정이 포함되지 않으므로([TOOL_COMMON.md](TOOL_COMMON.md) 8장), 적용 조건은 요약에 기재한다.
- 선택한 행에는 "모델 품목 선택이며 규제 적용·인증 보유를 확정하지 않았습니다." 가정을, 기본 후보에는 "품목 선택에서 맞는 행을 찾지 못한 결과입니다." 가정을 기록한다.
- 후보 판단이 있으면 "어린이제품법에서 구매대행 특례 조문을 찾지 못해 구매대행·사입을 나누지 않았습니다." 가정을 기록한다.

### 할 일

후보 판단마다 할 일 하나를 생성한다.

"[{품목} · {제도} 후보] 이 품목으로 분류되면 판매 전 {확인 대상} 확인해야 합니다. 구매대행·사입 모두 해당합니다."

| 제도 | 확인 대상 |
|---|---|
| 안전인증 | KC 안전인증을 받은 제품인지 인증번호로 |
| 안전확인 | KC 안전확인 신고가 된 제품인지 신고번호로 |
| 공급자적합성확인 | 공급자적합성확인(공통·개별 안전기준 시험)과 KC 표시가 된 제품인지 |

기본 후보의 품목 이름은 "공통안전기준 적용 품목"이다. 판단마다 해당 할 일을 `requirements`에 저장한다. 재실행에서 판단이 제외되면 Tool 실행기가 해당 할 일만 삭제한다.

### 질문

| 경우 | 질문 필드 |
|---|---|
| 제품 종류가 확인되지 않음 | `product_type` |
| 연령 조건이 없거나 충돌함 | `target_age` (제외 물품 판단 시 생략) |
| 선택 모델이 품목 확정에 추가로 필요하다고 표시한 조건 | 해당 필드 전부 |

- 선택 모델이 요청한 조건은 필드를 제한하지 않고 모두 질문한다.
- 질문 문장은 공용 질문 목록을 사용한다([TOOL_COMMON.md](TOOL_COMMON.md) 6장).

## 6. 근거

근거 문서는 다음 3개이며, 기준일별로 캐시한다([TOOL_COMMON.md](TOOL_COMMON.md) 7장).

| 문서 | 사용하는 부분 |
|---|---|
| 어린이제품 안전 특별법 | 제2조 제1호(어린이제품, 만 13세 이하), 제12호(공급자적합성확인대상) |
| 어린이제품 안전 특별법 시행규칙 | 별표 1(안전인증), 별표 2(안전확인), 별표 3(공급자적합성확인, 비고의 공통안전기준) |
| 어린이제품안전관리제도 운용요령 | 별표 3-5(제도별 적용범위) |

- 시행규칙 별표는 2칸 표(품목 | 적용 안전기준)이므로 코드가 행을 나눈다. 삭제된 품목은 제외한다.
- 운용요령 별표의 적용범위는 긴 설명문이므로 칸을 더 나누지 않고 품목 단위 원문으로 첨부한다.
- 운용요령 품목명은 시행규칙 품목명과 표기가 다르다(어린이용·아동용, 제품·용품, 띄어쓰기). 같은 제도 안에서 ① 공백을 제외한 이름 일치, ② 운용요령 품목명이 시행규칙 품목명에 포함(대상이 하나일 때), ③ 글자 유사도(0.4 이상, 품목 하나에 하나) 순으로 연결한다. 연결하지 못한 적용범위는 경고 로그로 기록하며, 해당 품목 행은 적용범위 없이 사용한다.
- 법 제2조 제1호에 "13세"가 없거나, 별표에서 품목 또는 공통안전기준 비고를 찾지 못하면 근거를 확인할 수 없는 것으로 처리한다.

| 판단 | 첨부 근거 |
|---|---|
| 선택한 행 | 시행규칙 별표 행("{번호}. {품목명} — 적용 안전기준: …"), 운용요령 적용범위(연결된 경우), 법 제2조 제1호(연령 포함이 확인된 경우) |
| 기본 후보 | 법 제2조 제1호·제12호, 시행규칙 별표 3 비고의 공통안전기준 문장 |
| 제외 물품, 연령 미포함 | 법 제2조 제1호 |

## 8. 상세 결과와 조회 기록

`ChildrenAssessment`:

| 칸 | 내용 |
|---|---|
| `target_age_raw` | 판정에 사용한 첫 연령 표기 |
| `intended_for_children` | 연령 판정 결과 (확정 아님) |
| `product_type` | 첫 제품 종류 값 |
| `certification_type` | 후보 판단의 제도 |
| `safety_management_required` | 항상 `None` (후보만으로 확정하지 않음) |
| `legal_sources` | 비움. 근거는 판단에만 첨부 |

`query` 주요 키:

| 키 | 내용 |
|---|---|
| `search_terms` | 모델 조회어 |
| `age_texts`, `age_state`, `age_source` | 판정에 사용한 연령 표기, 판정 결과, 추출 단계 값 사용 여부 |
| `excluded_kind` | 확인된 제외 물품 |
| `candidate_items`, `selected_items` | 선택 모델에 입력한 후보 행, 선택한 행 |
| `fallback` | 기본 후보 행 ID |
| `conflicted` | 충돌한 조건 |
| `documents` | 근거 문서 버전 |
| `dropped_facts`, `dropped_candidates`, `not_applicable`, `over_limit` | 공용 대조 기록 ([TOOL_COMMON.md](TOOL_COMMON.md)) |
