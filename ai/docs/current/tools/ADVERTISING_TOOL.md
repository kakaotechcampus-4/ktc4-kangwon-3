# 표시·광고 Tool

판매자 문구에서 실증이 필요한 광고 주장을 찾아 근거 조문과 판매 전 할 일을 제시하는 Tool이다. 다른 5개 규제 Tool과 달리 품목표를 조회하지 않으며, 모델 호출 한 번으로 문구를 검토한다. 공용 동작은 [TOOL_COMMON.md](TOOL_COMMON.md)에서 설명한다.

## 1. 개요

- 위반을 확정하지 않는다. 부당 여부는 소비자오인성·공정거래저해성으로 판단하며(지정고시 1), 상품 글만으로는 판매자가 실증자료를 보유하는지 알 수 없으므로 찾은 주장은 `POSSIBLY_REQUIRED`로 판정한다.
- 찾은 주장이 없으면 `NOT_REQUIRED` 판단 하나를 생성한다.
- 선택 단계의 판단과 관계없이 모든 상품에서 실행한다(`ALWAYS_RUN_TOOLS`).
- 결과 상태 계산에서 제외한다(`RESULT_STATUS_EXCLUDED_TOOLS`). 표시·광고 판단은 진단 결론을 바꾸지 않는다.
- `EvidenceSearchTool`이 아니라 `RegulatoryTool`을 직접 상속한다. 조건 추출, 원문 조각 대조, 후보 선택 단계가 없다.

| 역할 | 담당 |
|---|---|
| 판매자 문구에서 의심 문구 인용, 주장 유형 선택, 번역 | 모델 |
| 인용 대조, KC 표기 보충, 위험도, 화면 종류 구분, 근거 조문, 할 일 | 코드 |

## 2. 입력

- 검토 대상은 상품 정보의 `listing_text` 중 빈 줄을 제외한 모든 줄이다. 속성 원문은 검토하지 않는다.
- 재진단 답변은 "[사용자 답변] 질문 → 답변" 줄로 `listing_text` 끝에 추가되므로, 재진단 시에는 답변 줄도 검토 대상에 포함된다.
- 모델 입력의 상품 이름(`product_name`)과 카테고리(`category`)는 비워서 전달한다. 추출한 상품 이름이 판매자 제목 줄과 같아, 채우면 모델이 제목 줄의 효능 구절을 상품 이름으로 보고 제외하기 때문이다.
- 검토할 줄이 없으면 근거 조회와 모델 호출 없이 정보 부족으로 종료한다(5장).

## 3. 처리 흐름

```text
① 근거 조회 (코드)   표시광고법·고시·심사지침의 적용 판 조문
② 문구 검토 (모델)   줄별 검토 기록 + 주장(인용·유형·이유·번역)
③ 인용 대조 (코드)   listing_text에 없는 인용 제외, 같은 인용은 한 번
④ KC 표기 보충 (코드) 모델이 누락한 KC 표기를 주장으로 추가
⑤ 결과 조립 (코드)   주장별 위험도·화면 종류·근거·할 일
```

### 3.1 근거 조회

- 근거는 모델 호출 전에 조회한다. 근거가 없으면 판단을 생성할 수 없기 때문이다.
- 근거를 조회하지 못하면 `AdvertisingEvidenceError`로 Tool 실행이 실패한다. 다른 Tool처럼 정보 부족으로 종료하지 않는다.

### 3.2 문구 검토

모델은 다음을 출력한다.

| 칸 | 내용 |
|---|---|
| `line_checks` | 줄마다 후보 구절과 판단 기록. 주장보다 먼저 출력하게 하며, 결과에는 `raw_response`로만 저장 |
| `claims[].quote` | 판매자 문구의 원문 인용 |
| `claims[].risk_type` | 주장 유형 (4.1) |
| `claims[].reason` | 판단 이유. 화면에는 표시하지 않음 |
| `claims[].translation` | 인용이 한국어가 아닐 때의 짧은 번역 |

### 3.3 인용 대조와 KC 표기 보충

- 공백 차이와 영문 대소문자만 무시하고, 인용이 어느 한 줄 안에 있으면 유지한다. 없으면 제외하고 `query.dropped_quotes`에 기록한다. 같은 인용은 한 번만 유지한다.
- 코드가 판매자 문구에서 KC 표기("KC 인증", "KC 마크", "KC 안전인증", "KC 안전확인", "KC 공급자적합성", "KC 방송통신", "KC 적합성평가", "KC certified" 등)를 찾아 안전·인증 유형 주장으로 추가한다(`query.kc_claims_added`).
  - "KC 인증정보"(오픈마켓 사양 칸 이름)는 제외한다.
  - "KC 인증 없음", "KC 인증을 받지 않은" 등 인증이 없다는 문장은 제외한다.
  - 모델 인용과 겹치면 모델 인용을 유지한다.

## 4. 판정 규칙

### 4.1 주장 유형

「표시ㆍ광고 내용의 실증에 관한 운영 고시」 Ⅲ(실증자료 요청의 주요대상)과 지정고시의 유형을 기준으로 7가지로 나눈다.

| 유형 | 내용 |
|---|---|
| `body_effect` | 인체에 직접 영향을 미친다는 주장 |
| `safety_certification` | 안전·환경·신기술, 인증 표방 |
| `performance_quality` | 성능·효능·품질 |
| `ranking_absolute` | 순위, 최상급·절대적 표현, 비교 |
| `ingredient_material` | 원재료·성분 |
| `origin_maker` | 원산지·제조자·정품 |
| `warranty` | 보증·A/S |

### 4.2 위험도

- `body_effect` 유형이고 인용에 치료·예방·완치·질병·질환 중 하나가 있으면 `HIGH`, 그 밖의 주장은 `MEDIUM`이다.
- 상세 결과의 전체 위험도는 주장 위험도의 최댓값이며, 주장이 없으면 `LOW`다.

### 4.3 화면 종류

화면 안내와 근거는 모델 유형을 코드가 다시 나눈 10가지 종류로 결정한다.

| 종류 | 조건 |
|---|---|
| 의약품 효능 | `body_effect`이고 위험도 `HIGH` |
| 몸 효과 | `body_effect`이고 위험도 `MEDIUM` |
| 인증 | `safety_certification`이고 인용에 "인증", KC 표기, 외국 인증 표기(certif, CE, CCC, 3C, RoHS, FCC, FDA, UL, CB, GS, TÜV)가 있음 |
| 수상·특허·추천 | `safety_certification`이고 인용에 추천·권장·수상·특허·선정·award·patent·recommend가 있음. 판매자가 선택하였다는 뜻의 "선정한" 등은 제외 |
| 안전·친환경 | 그 밖의 `safety_certification` |
| 성능 | `performance_quality` |
| 원재료·성분 | `ingredient_material` |
| 원산지·제조자 | `origin_maker` |
| 순위·최상급 | `ranking_absolute` |
| 보증 | `warranty` |

## 5. 화면 문구

### 판단

| 경우 | 제목 | 판정·위험도 |
|---|---|---|
| 찾은 주장 | 원문 인용. 번역이 있으면 "인용(번역)" | `POSSIBLY_REQUIRED`·4.2 |
| 주장 없음 | 판매자 상품 문구 | `NOT_REQUIRED`·`LOW` |
| 문구 없음 | 판매자 상품 문구 | `INSUFFICIENT_INFORMATION`·`UNKNOWN` |

찾은 주장의 요약과 판단 근거는 화면 종류별 고정 문구다. 모델의 판단 이유는 내부 유형 이름이 포함될 수 있으므로 화면에 표시하지 않고 상세 결과에만 저장한다.

| 종류 | 요약 | 판단 근거 |
|---|---|---|
| 의약품 효능 | 의약품 효능처럼 읽히는 문구입니다. | 의약품이 아닌 상품을 객관적인 근거 없이 병을 치료하거나 예방하는 것처럼 광고하면 부당한 광고가 될 수 있습니다. |
| 몸 효과 | 몸에 효과가 있다는 주장입니다. | 효능을 내세운 문구는 시험 결과 같은 자료로 사실임을 보여 줄 수 있어야 합니다. 자료가 없으면 부당한 광고가 될 수 있습니다. |
| 인증 | 인증을 받았다는 표기입니다. | 받지 않은 인증을 받은 것처럼 적으면 부당한 광고가 될 수 있습니다. 상세페이지만으로는 알 수 없어 실제로 인증을 받았는지 확인이 필요합니다. |
| 수상·특허·추천 | 수상, 특허, 추천을 내세운 표기입니다. | 그런 사실이 없는데 있는 것처럼 적으면 부당한 광고가 될 수 있습니다. |
| 안전·친환경 | 안전하다거나 친환경이라는 주장입니다. | 안전, 환경에 관한 문구는 시험 성적서 같은 자료로 사실임을 보여 줄 수 있어야 합니다. … |
| 성능 | 성능을 수치로 내세우거나 효과를 보장하는 주장입니다. | 성능을 내세운 문구는 시험 결과 같은 자료로 사실임을 보여 줄 수 있어야 합니다. … |
| 원재료·성분 | 원재료나 성분을 내세운 주장입니다. | 원재료나 성분을 사실과 다르게, 또는 부풀려 적으면 부당한 광고가 될 수 있습니다. |
| 원산지·제조자 | 원산지, 제조사, 정품 여부를 내세운 표기입니다. | 원산지나 제조자를 사실과 다르게, 또는 헷갈리게 적으면 부당한 광고가 될 수 있습니다. |
| 순위·최상급 | 1위, 최고, 유일처럼 단정하거나 다른 상품보다 낫다고 비교하는 표현입니다. | 객관적인 근거 없이 순위, 최상급, 비교 표현을 쓰면 부당한 광고가 될 수 있습니다. |
| 보증 | 구체적인 조건 없이 보증을 약속한 문구입니다. | 보증 내용, 기간, 범위를 정확하게 기재하지 않으면 부당한 광고가 될 수 있습니다. |

- 찾은 주장에는 "판매자가 이 주장의 실증자료를 갖고 있는지는 확인하지 않았습니다." 가정을 기록한다.
- 주장 없음 판단의 요약은 "판매자 문구에서 문제가 될 만한 광고 표현을 찾지 못했습니다.", 판단 근거는 "효능, 인증, 성능, 원재료, 원산지, 최상급 표현, 보증 약속처럼 근거 자료가 필요한 주장이 있는지 확인했습니다."이며, 가정 "추출 단계가 listing_text로 옮긴 판매자 문구만 검토했습니다. 놓친 주장이 있을 수 있습니다."를 기록한다. 판단이 비면 검증 규칙이 Tool 실패로 판정하므로 이 판단을 생성한다.
- 문구 없음 판단의 요약은 "검토할 판매자 문구가 없습니다.", 판단 근거는 "상세페이지에서 판매자가 쓴 문구를 찾지 못해 광고 표현을 검토하지 못했습니다."다.

### 할 일

찾은 주장마다 한 건을 생성한다. 인용은 '원문'(번역) 형식으로 표기하며, 조사는 번역이 있으면 번역의 받침을 기준으로 결정한다.

| 종류 | 할 일 |
|---|---|
| 인증 | "{인용} 표기가 있습니다. 실제로 인증을 받은 제품인지 인증번호와 인증서로 확인하고, 확인되지 않으면 표기를 빼세요." |
| 수상·특허·추천 | "{인용} 표기가 있습니다. 수상, 특허, 추천 사실을 보여 줄 자료가 있는지 확인하고, 없으면 표기를 빼세요." |
| 보증 | "{인용} 문구가 있습니다. 누가, 언제까지, 어디까지 보증하는지 적고 실제로 지킬 수 있는지 확인하세요. …" |
| 원산지·제조자 | "{인용} 표기가 있습니다. 원산지나 제조자, 정품 여부가 사실인지 수입 서류로 확인하고, 다르면 표기를 고치세요." |
| 의약품 효능 | "{인용}은 의약품 효능처럼 읽힙니다. 의약품이 아닌 상품이면 문구를 빼거나 고치세요. …" |
| 그 밖의 종류 | "{인용}을 뒷받침하는 시험 결과나 조사 자료를 준비하세요. 자료가 없으면 문구를 빼거나 고치세요." |

판단마다 해당 할 일을 `requirements`에 저장한다.

### 질문

- 문구 없음일 때만 판매자 문구를 질문한다(`NO_LISTING_QUESTION`).
- 실증자료 보유 여부는 답변이 판단을 바꾸지 않으므로 질문하지 않고 할 일로만 안내한다.

### 진단 요약

표시·광고는 결과 상태 계산에서 제외되므로, 결과 상태가 구매대행 가능이고 표시·광고 판단 중 `REQUIRED`·`POSSIBLY_REQUIRED`가 있으면 진단 요약 끝에 " 다만 표시·광고 문구는 확인이 필요합니다."를 덧붙인다(`app/results/presenter.py`).

## 6. 근거

근거 문서는 다음 5개이며, 기준일별로 캐시한다([TOOL_COMMON.md](TOOL_COMMON.md) 7장).

| 문서 | 사용하는 부분 |
|---|---|
| 표시ㆍ광고의 공정화에 관한 법률 | 제3조 제1항, 제5조 제1항 |
| 부당한 표시·광고행위의 유형 및 기준 지정고시 | 4, 5 라, 10, 11, 12 가, 14 나 |
| 표시ㆍ광고 내용의 실증에 관한 운영 고시 | Ⅲ 1-4 |
| 수상·인증 등의 표시·광고에 관한 심사지침 | Ⅴ 1 |
| 소비자 안전에 관한 표시·광고 심사지침 | Ⅴ 1 가 |

- 법률은 조·항으로 인용한다. 본문이 한 덩어리인 고시·지침은 표지 문구로 시작하는 줄 하나를 인용한다. 표지 문구로 시작하는 줄이 정확히 하나가 아니면 근거를 확인할 수 없는 것으로 처리한다.
- 줄의 나머지 문구가 개정되면 인용도 개정된 문구로 바뀐다.

### 주장별 근거

모든 주장에 법 제3조 제1항, 제5조 제1항, 유형별 실증 대상 항목을 첨부하고, 유형별 근거를 다음과 같이 덧붙인다.

| 유형 | 실증 운영 고시 | 유형별 근거 |
|---|---|---|
| `body_effect` | Ⅲ 1 | 지정고시 5 라 |
| `safety_certification` | Ⅲ 2 | 수상·인증 심사지침 Ⅴ 1 (안전·친환경 종류는 제외) |
| `performance_quality` | Ⅲ 3 | 지정고시 5 라 |
| `ingredient_material` | Ⅲ 3 | 지정고시 4 |
| `ranking_absolute` | Ⅲ 4 | 지정고시 14 나 |
| `origin_maker` | Ⅲ 4 | 지정고시 10 |
| `warranty` | Ⅲ 4 | 지정고시 11 |

- 의약품 효능 종류는 소비자 안전 심사지침 Ⅴ 1 가를 덧붙인다.
- 수상·특허·추천 종류 중 추천·권장 표기는 지정고시 12 가를 덧붙인다.
- 주장 없음 판단에는 법 제5조 제1항을 첨부한다.

## 7. 실패·정보 부족

| 상황 | 처리 |
|---|---|
| 근거 조문을 읽지 못함 | `AdvertisingEvidenceError` (Tool 실패) |
| 모델 호출 실패, 응답이 출력 형식과 불일치 | `AdvertisingReviewError`. 실패 문구에는 원인 예외 이름만 포함 |
| 검토할 문구 없음 | 정보 부족 + 판매자 문구 질문 |
| 찾은 주장 없음 | `NOT_REQUIRED` 판단 |

## 8. 상세 결과와 조회 기록

`AdvertisingAssessment`:

| 칸 | 내용 |
|---|---|
| `reviewed_phrases` | 검토한 판매자 문구 전체 |
| `detected_phrases` | 주장별 인용, 유형, 위험도, 모델 판단 이유, 실증 필요 여부(항상 참) |
| `overall_risk` | 전체 위험도 (4.2). 문구 없음이면 `UNKNOWN` |
| `legal_sources` | 판단에 첨부한 근거 전체. 다른 Tool과 달리 채움 |

`query` 키:

| 키 | 내용 |
|---|---|
| `listing_lines` | 검토한 줄 수 |
| `prompt_sha256` | 사용한 프롬프트의 해시 |
| `dropped_quotes` | 원문과 대조되지 않아 제외한 인용 |
| `kc_claims_added` | 코드가 추가한 KC 표기 주장 수 |
| `documents` | 근거 문서 버전 |
