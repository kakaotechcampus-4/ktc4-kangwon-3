# 식품·의약품 안전 Tool

상품이 식품용 기구·용기, 식품·건강기능식품, 화장품(기능성화장품·사용할 수 없는 원료 포함), 의료기기에 해당할 가능성을 판단하고, 영역별 근거 조문과 판매 방식별 할 일을 제시하는 Tool이다. 실행 틀, 원문 대조, 질문, 법령 조회 등 공용 동작은 [TOOL_COMMON.md](TOOL_COMMON.md)에서 설명한다.

## 1. 개요

- "이 상품이 화장품인가"와 같은 해당 여부는 모델이 원문 근거로 판단하고, 코드는 그 판단에 법 조문과 할 일을 덧붙인다.
- 판정은 `POSSIBLY_REQUIRED`(후보) 또는 `INSUFFICIENT_INFORMATION`(정보 부족)만 사용한다. 확정 판정(`REQUIRED`·`NOT_REQUIRED`)은 생성하지 않는다.
- 한 상품이 여러 영역에 동시에 해당할 수 있다(예: 체온 측정 젖병은 식품용 기구와 의료기기).
- 제품 분류만 판단한다. 광고 문구 자체의 위법 가능성은 표시·광고 Tool이 판단한다.
- 판매 방식(구매대행·사입)은 상품 정보로 알 수 없으므로 두 경우의 할 일을 함께 제시한다.

| 역할 | 담당 |
|---|---|
| 필수 판단 3개(음식 접촉·먹는 것·바르는 것)와 원문 근거, 조건 값과 인용, 의료기기 조회어, 기능성화장품 범위 번호 | 모델 |
| 인용 대조, 판단 칸 상태 결정, 영역별 조문·할 일 첨부, 금지 원료 이름 대조, 의료기기 품목 조회 | 코드 |
| 의료기기 후보 품목 중 해당하는 품목 선택과 선택 이유 | 모델 |

## 2. 입력

### 조건 필드

| 필드 | 표시 이름 | 값 |
|---|---|---|
| `food_contact` | 음식 접촉 용도 | 판단 결과("예"·"아니오") |
| `edible` | 먹는 것 여부 | 판단 결과 |
| `skin_applied` | 바르는 것 여부 | 판단 결과 |
| `product_type` | 제품 종류 | 원문 인용 |
| `material` | 재질 | 원문 인용 |
| `intended_use` | 용도 | 원문 인용 |
| `health_claim` | 효능 표방 문구 | 원문 인용 (질병·신체 기능 효능) |
| `beauty_claim` | 피부·모발 효과 문구 | 원문 인용 (미백·주름·자외선 차단 등) |
| `ingredient` | 성분 | 원문 인용 (성분·원료 이름 하나) |

- 필수 판단 3개는 모델 출력 형식에서 필수 칸이다. 답은 "예"·"아니오"·"모름" 중 하나이며, "모름"이 아니면 원문 근거 인용을 함께 출력한다.
- 판단 칸은 값이 판단 결과이므로 인용만 원문과 대조한다. 그 밖의 칸은 값과 인용을 모두 대조한다.
- 조건 추출 모델은 의료기기 품목표 조회용 일반 명칭(`device_terms`)과, 피부·모발 효과 문구가 해당하는 기능성화장품 범위 번호(`functional_types`)를 함께 출력한다.
- 모델 힌트에 속성 이름과 값을 포함한다(`hints_with_attributes`).
- 인용할 원문이 없으면 질문 없이 정보 부족 판단만 생성한다.

## 3. 처리 흐름

```text
① 근거 조회 (코드)     법령 조문·의료기기 품목표·금지 원료 별표·기능성화장품 범위
② 조건 추출 (모델)     필수 판단 3개 + 원문 근거, 조건 값과 인용, 의료기기 조회어, 기능성 범위 번호
③ 판단 칸 상태 (코드)  예·아니오·미정, 미정이면 질문
④ 의료기기 (코드·모델) 품목표 조회 → 품목 선택
⑤ 영역별 규칙 (코드)   식품용 기구·식품·화장품 판단에 조문·할 일 첨부
⑥ 결과 조립 (코드)     근거, 판매 방식별 할 일, 질문
```

### 3.1 근거 조회

- 근거는 조건 추출보다 먼저 조회한다. 기능성화장품 범위(화장품법 시행규칙 제2조)의 호 목록을 조건 추출 모델 입력에 포함하기 위함이다.
- 근거를 확인할 수 없으면 "식약 근거 법령의 시행 버전·본문을 확인하지 못해 근거 조문 없이 안내했습니다." 가정을 기록하고, 근거 조문 없이 판단을 계속한다. 이 경우 기능성화장품 대응, 금지 원료 대조, 의료기기 품목 조회는 수행하지 않는다.

### 3.2 판단 칸 상태

| 원문과 대조된 값 | 상태 | 처리 |
|---|---|---|
| "예"만 있음 | 해당 | 영역 판단 생성 |
| "아니오"만 있음 | 해당 없음 | 판단 없음 |
| "예"와 "아니오"가 함께 있음 | 미정 | 질문 + "{표시 이름}의 원문 근거가 서로 달라 해당 여부를 정하지 않았습니다." |
| 없음 (모델은 "예"였으나 인용이 원문과 일치하지 않아 제외됨) | 미정 | 질문 + "{표시 이름}를 '예'로 볼 원문 근거를 확인하지 못해 해당 여부를 정하지 않았습니다." |
| 없음 (`food_contact`만, 상품 입력의 음식 접촉 속성이 참) | 미정 | 질문 |
| 없음 (그 밖의 경우) | 미정 | 판단 없음 |

### 3.3 의료기기 조회

- 먹거나 바르는 상품이 아니고(`edible`·`skin_applied`가 모두 해당이 아님), 효능 표방 문구 또는 의료기기 조회어가 있을 때만 조회한다.
- 다른 영역의 판단보다 먼저 실행한다. 이 단계에서 기록한 가정(품목 미대응, 제외한 선택)이 이후 생성하는 판단에도 포함되도록 하기 위함이다.
- 조회어는 의료기기 조회어 최대 3개와 제품 종류·용도 값을 합하여 구성한다.
- 순위는 품목명·중분류·정의와 조회어의 글자 2개 단위 유사도로 산정하며, 품목명이 조회어에 그대로 포함되면 가산한다(`common.ranking.rank_rows`). 상위 8개를 선택 모델에 입력하며, 정의는 앞 200자만 입력한다.
- 선택은 공용 후보 선택 대조를 거친다([TOOL_COMMON.md](TOOL_COMMON.md) 5장). 선택 수 상한은 3개이며, 초과분은 "품목 선택이 3개를 넘어 N개는 쓰지 않았습니다." 가정으로 기록한다. 대조되지 않은 선택은 "후보 품목과 대조되지 않은 선택 N개를 제외했습니다." 가정으로 기록한다.
- 등급과 근거 인용은 모델이 작성하지 않으며, 코드가 선택한 품목 행에서 첨부한다.

## 4. 판정 규칙

### 4.1 영역별 판단

| 영역 | 조건 | 제목 |
|---|---|---|
| 식품용 기구·용기 | 음식 접촉 "해당" | 식품용 기구·용기 후보 — 수입신고 대상 |
| 식품·건강기능식품 | 먹는 것 "해당" | 식품·건강기능식품 후보 — 수입신고 대상 |
| 화장품 | 바르는 것 "해당" | 화장품 후보 — 화장품책임판매업 등록 대상 |
| 기능성화장품 | 화장품 후보 + 피부·모발 효과 문구 + 모델이 대응한 번호가 시행규칙 제2조에 실제로 있는 호 | 기능성화장품 후보 — 시행규칙 제2조 제N호 |
| 사용할 수 없는 원료 | 화장품 후보 + 성분명이 금지 원료 별표 1의 이름과 일치 | 4.2 참조 |
| 의료기기 | 3.3의 조회 조건 + 선택한 품목 | 의료기기 후보 — {품목명} ({등급}등급) |
| 의료기기 품목 미확인 | 3.3의 조회 조건 + 효능 표방 문구 있음 + 품목을 정하지 못함 | 의료기기 해당 여부 — 품목 미확인 |

- 후보 판단의 위험도는 `MEDIUM`이다. 일반 금지 원료만 `HIGH`다.
- 의료기기 품목 미확인 판단은 `INSUFFICIENT_INFORMATION`(위험도 `MEDIUM`)이며, 의료기기가 아니라면 의료기기와 비슷한 효능으로 오인될 표시·광고를 할 수 없다는 안내(의료기기법 제26조 제7항)를 포함한다.
- 의료기기 조회 조건을 충족하였으나 효능 표방 문구가 없고 품목을 정하지 못하면 판단을 생성하지 않고 "의료기기 품목과 대응하지 못했습니다: {이유} 비대상 판단이 아닙니다." 가정만 기록한다.
- 먹거나 바르는 상품에 효능 표방 문구가 있으면 의료기기 품목으로 조회하지 않고, "먹거나 바르는 상품의 질병·신체 기능 효능 문구(…)는 의약품으로 오인될 수 있습니다. 표시·광고 Tool 결과와 함께 봐야 합니다." 가정을 기록한다.
- 먹는 상품의 효능 표방 문구와 피부·모발 효과 문구는 모두 건강기능식품 확인 대상이다.
- 바르는 상품의 효과 문구는 효능 표방 문구 칸과 피부·모발 효과 문구 칸 중 어디에 추출되었든 기능성화장품 대응의 근거로 사용한다.

### 4.2 사용할 수 없는 원료

성분명을 「화장품 안전기준 등에 관한 규정」 별표 1의 원료명·화학물질명과 글자로 대조한다.

- 대조 키는 공백·가운뎃점·대소문자 차이를 무시한다. 원료명은 원문 그대로, 각주 번호와 "및 그 염류·화합물" 등을 제거한 이름, 화학물질명으로 대조한다.
- 영문명(INCI)·이명으로 기재된 원료는 찾지 못한다.
- 같은 원료를 여러 번 인용하여도 원료 행마다 판단을 하나만 생성한다.

| 원료 행 | 제목 | 위험도 |
|---|---|---|
| 일반 | 사용할 수 없는 원료 포함 가능성 — {원료} | `HIGH` |
| 조건부 (원료명에 "적합하지", "초과", "이하", "이상", "다만", "제외", "함유", "경우" 등 사용 조건이 기재된 행) | 사용할 수 없는 원료 해당 여부 확인 — {원료} | `MEDIUM` |

- 조건부 원료는 이름이 일치하여도 조건 해당 여부를 확인하기 전에는 금지 원료로 판단할 수 없으므로, 원료 규격서로 확인하도록 안내한다.
- 사용상의 제한이 필요한 원료(별표 2)는 대조하지 않는다.

### 4.3 영역별 고정 가정

| 영역 | 가정 |
|---|---|
| 식품용 기구·용기 | "상품 원문의 쓰임으로 본 후보이며 식품용 기구 해당을 확정하지 않았습니다." 재질이 없으면 "재질이 확인되지 않아 적용할 기구 기준·규격(재질별)을 정하지 않았습니다." |
| 식품·건강기능식품 | "건강기능식품의 인정된 기능성 원료 대조는 하지 않았습니다." |
| 화장품 | "의약품(약사법)에 해당하는 물품은 화장품에서 제외됩니다(화장품법 제2조 제1호 단서)." |
| 화장품 (기능성 대응 실패) | "피부·모발 효과 문구(…)를 기능성화장품 범위에 대응하지 못했습니다." |
| 화장품 (성분 없음) | "성분 정보가 없어 사용할 수 없는 원료를 대조하지 못했습니다." |
| 화장품 (일치 원료 없음) | "성분명 글자 대조에서 사용할 수 없는 원료와 같은 이름이 없었습니다. 다른 이름(영문명·이명)으로 적힌 원료는 찾지 못하므로 안전하다는 뜻은 아닙니다." |
| 의료기기 | "모델 품목 선택이며 의료기기 해당·허가 보유를 확정하지 않았습니다." |
| 의료기기 품목 미확인 | "효능 문구 자체의 표시·광고 위반 가능성은 표시·광고 Tool 결과와 함께 봐야 합니다." |

## 5. 화면 문구

### 판단

| 영역 | 요약 | 판단 근거 |
|---|---|---|
| 식품용 기구·용기 | "음식에 직접 닿는 용도로 보여, 식품용 기구(식품위생법 제2조 제4호)라면 판매 목적으로 수입할 때 수입신고 대상일 가능성이 있습니다(확정 아님)." | 음식 접촉 판단의 원문 인용 |
| 식품·건강기능식품 | "사람이 먹거나 마시는 상품으로 보여, 식품(식품위생법 제2조 제1호)이라면 … 수입신고 대상일 가능성이 있습니다(확정 아님)." 효능 문구가 있으면 건강기능식품 해당 여부 확인 문장을 덧붙임 | 먹는 것 판단의 원문 인용 |
| 화장품 | "몸에 바르거나 뿌려 쓰는 상품으로 보여, 화장품(화장품법 제2조 제1호)이라면 … 화장품책임판매업 등록이 필요할 가능성이 있습니다(확정 아님)." | 바르는 것 판단의 원문 인용 |
| 기능성화장품 | "피부·모발 효과 문구(…)가 기능성화장품 범위에 해당할 수 있습니다(확정 아님)." + 심사·보고 필요 안내 | 해당할 수 있는 호와 원문 |
| 사용할 수 없는 원료 | 원료명 일치 사실과 판매·수입대행 알선 금지(화장품법 제15조 제5호) 안내 | 원문 성분 표기 |
| 의료기기 | "이 품목으로 분류되면 의료기기({등급}등급)일 가능성이 있습니다(확정 아님)." + 품목 정의 | 선택 모델의 선택 이유 |
| 의료기기 품목 미확인 | 효능 표방 문구, 의료기기라면 수입허가 등 필요, 아니라면 오인 표시·광고 금지 | 품목을 정하지 못한 이유 |
| 정보 부족 (판단 없음) | "상품 설명에서 음식에 닿거나 먹거나 바르는 쓰임, 질병·신체 효능 문구를 찾지 못해 식품·화장품·의료기기에 해당하는지 판단하지 못했습니다." | — |

정보 부족 판단의 제목은 "식품·화장품·의료기기 해당 여부"다.

### 할 일

할 일 머리말의 상품 이름은 첫 제품 종류 값, 없으면 상품명, 그것도 없으면 "상품"을 사용한다.

| 영역 | 머리말 | 사입·수입 | 구매대행 |
|---|---|---|---|
| 식품용 기구·식품 | [{상품} · {식품용 기구·식품} 후보] | 수입식품등 수입·판매업 영업등록 후 판매 목적 수입마다 수입신고 | 인터넷 구매 대행업 영업등록, 구매대행 수입분의 수입신고 대상 여부 확인 필요 |
| 건강기능식품 표방 | [{상품} · 기능성 표방 '…'] | 기능성 원료로 제조한 건강기능식품이어야 함. 일반 식품이면 표방 문구는 표시·광고 Tool 결과와 함께 확인 (한 건) | |
| 화장품 | [{상품} · 화장품 후보] | 화장품책임판매업 등록, 책임판매관리자·품질관리 기준 | 수입대행형 거래 알선도 책임판매업이므로 등록 필요(화장품법 제2조 제11호) |
| 기능성화장품 | [{상품} · 기능성화장품 후보(시행규칙 제2조 제N호)] | 품목별 심사 또는 보고서 제출. 없으면 판매·수입대행 알선 금지 (한 건) | |
| 사용할 수 없는 원료 | [성분 '…' · 사용할 수 없는 원료 '…'] 또는 [성분 '…' · 조건부 금지 원료 '…'] | 판매·수입대행 알선·진열 금지. 일반 원료는 전성분표 확인, 조건부 원료는 원료 규격서·시험성적서로 조건 확인 (한 건) | |
| 의료기기 | [{품목} · 의료기기 {등급}등급 후보] | 수입업허가·품목 수입허가·인증·신고, 판매업신고. 허가 없는 의료기기 판매·진열 금지 | 자가 사용용 수입은 허가 면제될 수 있으나 허가 없는 의료기기 판매·진열은 금지, 확인 필요 |
| 의료기기 품목 미확인 | [효능 표방 문구 '…'] | 의료기기가 아니라면 오인 표시·광고 금지. 문구 삭제 또는 의료기기 해당 여부 우선 확인 (한 건) | |

판단마다 해당 판단의 할 일을 `requirements`에 저장한다. 재실행에서 판단이 제외되면 Tool 실행기가 해당 할 일만 삭제한다.

### 질문

질문은 판단에 영향을 주는 조건에만 생성한다.

| 경우 | 질문 필드 |
|---|---|
| 판단 칸의 원문 근거가 "예"와 "아니오"로 엇갈림 | 해당 판단 칸 |
| 모델은 "예"로 판단하였으나 인용이 원문과 일치하지 않아 제외됨 | 해당 판단 칸 |
| 상품 입력의 음식 접촉 속성은 참이나 음식 접촉 판단의 원문 근거가 없음 | `food_contact` |
| 선택한 의료기기 품목의 확정에 용도가 필요함 | `intended_use` |

- 의료기기 품목 선택 모델이 용도 외의 조건을 추가로 필요하다고 표시하면 질문하지 않고 "품목 확정에는 … 확인이 더 필요합니다." 가정으로 기록한다.
- 질문 문장은 공용 질문 목록을 사용한다([TOOL_COMMON.md](TOOL_COMMON.md) 6장).

## 6. 근거

근거 문서는 다음 10개이며, 기준일별로 캐시한다([TOOL_COMMON.md](TOOL_COMMON.md) 7장).

| 문서 | 사용하는 부분 |
|---|---|
| 식품위생법 | 제2조 제1호(식품), 제4호·제5호(기구·용기) |
| 수입식품안전관리 특별법 | 제2조 제1호(수입식품등), 제14조 제1항, 제15조 제1항, 제20조 제1항 |
| 수입식품안전관리 특별법 시행령 | 제2조 제1호·제3호 |
| 건강기능식품에 관한 법률 | 제3조 제1호·제2호 |
| 화장품법 | 제2조 제1호·제2호·제11호, 제3조 제1항-제3항, 제4조 제1항, 제8조 제1항, 제15조 제1호-제5호 |
| 화장품법 시행규칙 | 제2조(기능성화장품의 범위) |
| 화장품 안전기준 등에 관한 규정 | 제3조, 별표 1(사용할 수 없는 원료) |
| 의료기기법 | 제2조 제1항, 제15조 제1항·제2항, 제17조 제1항·제2항, 제26조 제1항·제7항 |
| 의료기기법 시행규칙 | 제32조 제1항 |
| 의료기기 품목 및 품목별 등급에 관한 규정 | 별표 1(품목·등급) |

- 조문 전체를 인용하지 않고, 판단에 사용하는 항·호만 시작·끝 표지 문구로 잘라 인용한다. 표지 문구를 찾지 못하면(개정으로 문구가 바뀐 경우 등) 근거를 확인할 수 없는 것으로 처리한다.
- 의료기기법 제26조는 본문에 제8항이 있으면 제7항까지만 인용한다.
- 별표에서 품목·원료를 찾지 못하거나 기능성화장품 범위가 비어 있으면 근거를 확인할 수 없는 것으로 처리한다.
- 화장품법 시행령과 기구·용기 기준·규격 고시는 조회하지 않는다. 재질별 기준·규격은 판단하지 않는다.

| 판단 | 첨부 근거 |
|---|---|
| 식품용 기구·용기 | 식품위생법 제2조 제4호·제5호, 수입식품법 제14조·제15조·제20조, 시행령 제2조 |
| 식품·건강기능식품 | 식품위생법 제2조 제1호, (효능 문구가 있으면) 건강기능식품법 제3조, 수입식품법 제2조 제1호와 위 수입 근거 |
| 화장품 | 화장품법 제2조 제1호·제11호, 제3조 |
| 기능성화장품 | 화장품법 제2조 제2호, 시행규칙 제2조 해당 호, 제4조 제1항, 제15조 |
| 사용할 수 없는 원료 | 화장품법 제8조 제1항, 안전기준 규정 제3조, 별표 1 해당 행, 화장품법 제15조 |
| 의료기기 | 의료기기법 제2조 제1항, 품목·등급 규정 별표 1 해당 행, 제15조, 제17조, 제26조 제1항, 시행규칙 제32조 제1항 |
| 의료기기 품목 미확인 | 의료기기법 제2조 제1항, 제26조 제7항 |

## 8. 상세 결과와 조회 기록

`FoodDrugAssessment`:

| 칸 | 내용 |
|---|---|
| `regulatory_categories` | 후보를 생성한 영역 (식품용 기구·용기, 식품·건강기능식품, 화장품, 기능성화장품, 의료기기) |
| `detected_claims` | 원문과 대조된 효능 표방 문구·피부·모발 효과 문구 |
| `ingredients_or_materials` | 원문과 대조된 재질·성분 |
| `applicable_requirements` | 판단에 첨부한 근거의 법령 이름 |
| `regulated` | 항상 `None` (후보만으로 확정하지 않음) |
| `legal_sources` | 비움. 근거는 판단에만 첨부 |

`query` 주요 키:

| 키 | 내용 |
|---|---|
| `food_contact`, `edible`, `skin_applied` | 판단 칸 상태 (`true`·`false`·`null`) |
| `health_claims` | 효능 표방 문구 |
| `functional_types`, `banned_ingredients` | 대응한 기능성화장품 호, 일치한 금지 원료 |
| `device_terms`, `candidate_items`, `selected_items` | 의료기기 조회어, 후보 품목, 선택한 품목 |
| `categories` | 후보를 생성한 영역 |
| `documents` | 근거 문서 버전 |
| `dropped_facts`, `dropped_candidates`, `not_applicable`, `over_limit` | 공용 대조 기록 ([TOOL_COMMON.md](TOOL_COMMON.md)) |
