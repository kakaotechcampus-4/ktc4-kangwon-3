# 전파 Tool

방송통신기자재등의 적합성평가에 관한 고시의 대상기자재 표에서 상품에 해당할 가능성이 있는 기자재를 찾고, 평가유형(적합인증·적합등록·자기적합확인)과 판매 방식별 할 일을 제시하는 Tool이다. 실행 틀, 원문 대조, 질문, 법령 조회 등 공용 동작은 [TOOL_COMMON.md](TOOL_COMMON.md)에서 설명한다.

## 1. 개요

- 무선 기능이 있는 상품만 판단한다. 고시 별표 1의 1-10절(무선설비 기기)이 대상이며, 11절(전자파장해 기기, 유선 전자파적합성)은 범위에서 제외한다.
- 법령 원문 전체를 모델에 입력하지 않는다. 대상기자재 표에서 상품과 유사한 행 몇 개만 조회하고, 그중 해당하는 행을 모델이 선택한다.
- 판정은 `POSSIBLY_REQUIRED`(후보) 또는 `INSUFFICIENT_INFORMATION`(정보 부족)만 사용한다. 확정 판정(`REQUIRED`·`NOT_REQUIRED`)은 생성하지 않는다.
- 평가유형은 모델이 판단하지 않고, 선택한 행의 표시(○)를 그대로 사용한다.

| 역할 | 담당 |
|---|---|
| 상품 조건 값과 원문 인용 추출, 조회어 선택 | 모델 |
| 인용 대조, 무선 기능 확인, 주파수 정규화, 대상기자재 조회, 평가유형·근거 첨부 | 코드 |
| 후보 행 중 상품에 해당하는 행 선택과 선택 이유 | 모델 |

## 2. 입력

### 조건 필드

| 필드 | 표시 이름 | 질문 여부 |
|---|---|---|
| `product_type` | 제품 종류 | 질문 (필수) |
| `wireless_feature` | 무선 기능 | 질문 (필수) |
| `frequency` | 사용 주파수 | 질문하지 않음 |
| `output_power` | 출력 | 질문하지 않음 |
| `intended_use` | 제품 용도 | 질문하지 않음 |

- 대상기자재 표는 상품명이 아니라 무선 기술·용도로 분류되어 있다(예: 블루투스 이어폰은 "특정소출력무선기기 > 무선데이터통신시스템용무선기기"). 상품별 동의어 사전 대신, 표에서 읽은 분류명 목록("분류 > 세부 분류", 번호 제외)을 조건 추출 모델에 입력하고 조회어(`search_terms`, 최대 3개)를 그 안에서 선택하게 한다.
- 분류명 목록을 조회할 수 없으면 목록 없이 조건을 추출한다.
- 인용할 원문이 없으면 제품 종류와 무선 기능을 질문한다.

## 3. 처리 흐름

```text
① 분류명 목록 조회 (코드)  조건 추출 모델에 입력할 분류명
② 조건 추출 (모델)         제품 종류·무선 기능·주파수·출력·용도 + 원문 인용, 조회어
③ 코드 규칙                무선 기능 확인, 주파수 MHz 정규화
④ 대상기자재 조회 (코드)   고시 별표 1의 1-10절 중 유사한 상위 8개
⑤ 기자재 선택 (모델)       후보 행 중 해당하는 행 최대 3개 + 선택 이유
⑥ 결과 조립 (코드)         행 원문·조문 근거, 평가유형, 판매 방식별 할 일
```

### 3.1 대상기자재 조회

- 조회어는 모델 조회어, 무선 기능·제품 종류·제품 용도 값, 상품명·카테고리를 합하여 구성한다.
- 순위는 분류 경로·비고와 조회어의 글자 2개 단위 유사도로 산정하며, 분류명이 조회어에 그대로 포함되면 가산한다(`common.ranking.rank_rows`).
- 제품 종류 또는 무선 기능이 확인되지 않으면 조회하지 않는다.
- 근거 문서를 확인할 수 없으면 "법령 대상기자재의 시행 버전·본문을 확인하지 못해 기자재를 대조하지 않았습니다." 가정을 기록하고 정보 부족으로 종료한다.
- 유사한 행이 없으면 "상품과 비슷한 대상기자재 행을 찾지 못했습니다. 비대상 판단이 아닙니다." 가정을 기록한다.

### 3.2 기자재 선택

선택 모델에는 다음을 입력한다.

| 입력 | 내용 |
|---|---|
| 조건 | 원문과 대조된 조건 |
| 상품 대역 | 정규화한 주파수 범위(MHz) |
| 절 비고 | 후보 행이 속한 절의 비고(예: 5절 전자파흡수율 적용 조건). 절마다 1500자까지 |
| 후보 | 행 ID, 절, 분류 경로, 평가유형, 적용 분야, 행 대역(MHz), 비고 |

선택은 공용 후보 선택 대조를 거친다([TOOL_COMMON.md](TOOL_COMMON.md) 5장). 대조되지 않은 선택은 "후보 행과 대조되지 않은 선택 N개를 제외했습니다." 가정으로 기록한다. 해당하는 행이 없으면 "후보 행 중 상품에 맞는 기자재를 고르지 못했습니다. 비대상 판단이 아닙니다." 가정을 기록한다.

## 4. 판정 규칙

### 4.1 무선 기능

- 원문과 대조된 무선 기능 조건이 없으면 후보를 생성하지 않고 무선 기능을 질문한다. "상품 원문에서 무선 기능 근거를 찾지 못해 무선기기 후보를 내지 않았습니다. 비대상 판단이 아닙니다(유선 전자파적합성 기기는 이 Tool 범위 밖)." 가정을 기록한다.

### 4.2 주파수

- 주파수 조건과 무선 기능 값 안의 표기(예: "Bluetooth 5.0 (2.4GHz)")를 MHz 범위로 정규화한다. 범위 표기(`5150∼5350㎒`)와 단일 값(`2.4GHz`, `13.56㎒`, `125kHz`)을 해석하며, 단위는 kHz·MHz·GHz와 ㎑·㎒·㎓다.
- 정규화한 대역은 행 대역과 함께 선택 모델에 입력한다. 상품 표기는 대략값이므로 대역 불일치를 이유로 행을 제외하지 않는다.
- 주파수는 판단을 바꾸지 않으므로 질문하지 않는다. 주파수가 없으면 "상품 원문에서 사용 주파수를 찾지 못해 후보 행의 대역과 대조하지 않았습니다." 가정을 기록한다.

### 4.3 평가유형과 근거 항

| 평가유형 | 전파법 제58조의2 |
|---|---|
| 적합인증 | 제2항 |
| 적합등록 | 제3항 |
| 자기적합확인 | 제4항 |

행에 평가유형이 여러 개 표시되면 "적합인증·적합등록"의 형식으로 이어서 표기하고, 해당하는 항을 모두 근거로 첨부한다.

### 4.4 개인 사용 반입 면제

전파법 시행령 별표 6의2의 개인 사용 목적 반입 면제 목을 판단 요약, 할 일, 근거에 조건부로 반영한다. 구매대행이 이 면제에 해당하는지는 판단하지 않고 확인이 필요하다고 안내한다.

## 5. 화면 문구

### 판단

| 경우 | 제목 | 요약 |
|---|---|---|
| 선택한 행 | {평가유형} 대상기자재 후보 — {기자재명} | "방송통신기자재 {평가유형} 대상일 가능성이 있습니다({절} > {분류 경로}).\n판매 목적 수입은 판매 전 적합성평가가 필요합니다. 개인 사용 목적 반입은 면제 대상일 수 있습니다(시행령 별표 6의2)." |
| 정보 부족 | 방송통신기자재 적합성평가 대상 판정 | "상품 설명에서 무선 기능(블루투스, Wi-Fi 등)을 찾지 못하거나 해당하는 기자재 항목을 정하지 못해 적합성평가 대상인지 판단하지 못했습니다." |

- 선택한 행의 위험도는 `MEDIUM`이고, 판단 근거는 선택 모델이 작성한 선택 이유다.
- 모든 후보 판단에 "모델 기자재 선택이며 적합성평가 대상·인증 보유를 확정하지 않았습니다. 평가유형은 고시 별표 1의 행 표시를 그대로 옮겼습니다." 가정을 기록한다.
- 선택 모델이 추가로 필요하다고 표시한 조건 중 질문 대상이 아닌 조건(주파수·출력·용도)은 "기자재 확정에는 … 확인이 더 필요합니다." 가정으로 기록한다.

### 할 일

선택한 행마다 두 건을 생성한다. 머리말은 "[{기자재명} · {평가유형} 후보]"다.

| 판매 방식 | 할 일 |
|---|---|
| 사입·수입 판매 | "이 기자재로 분류되면 판매 전 {평가유형}을(를) 받은 제품인지 KC 적합성평가 번호로 확인해야 합니다." |
| 구매대행 | "소비자가 개인 사용 목적으로 {면제 수량} 반입하는 기자재는 적합성평가 면제 대상일 수 있습니다(전파법 시행령 별표 6의2, 반입일부터 1년 이내 판매 시 제외). 구매대행이 이 면제에 해당하는지는 확인이 필요합니다." |

판단마다 해당 행의 할 일을 `requirements`에 저장한다. 재실행에서 판단이 제외되면 Tool 실행기가 해당 할 일만 삭제한다.

### 질문

- 질문 대상은 판단을 바꾸는 조건인 제품 종류와 무선 기능뿐이다.
- 제품 종류는 값이 여러 개여도 충돌로 판정하지 않고 모두 조회어로 사용한다.
- 질문 문장은 공용 질문 목록을 사용한다([TOOL_COMMON.md](TOOL_COMMON.md) 6장).

## 6. 근거

근거 문서는 다음 3개이며, 기준일별로 캐시한다([TOOL_COMMON.md](TOOL_COMMON.md) 7장).

| 문서 | 사용하는 부분 |
|---|---|
| 전파법 | 제58조의2 제1항(적합성평가 의무), 제2항-제4항(평가유형별) |
| 전파법 시행령 | 별표 6의2 개인 사용 반입 면제 목 |
| 방송통신기자재등의 적합성평가에 관한 고시 | 별표 1의 1-10절(대상기자재 표, 절 비고) |

### 대상기자재 표 해석

- 칸 줄이 어긋나도 행 오른쪽 끝 10칸(적용 분야 5, 평가유형 3, 기기부호, 기타사항)은 순서가 고정이므로 오른쪽부터 센다.
- 바깥 분류가 여러 행에 해당하고 이름이 부분 가로선 줄에 이어지는 경우("라.특정소출력 / 무선기기")에는 이어 붙인다. 삭제된 행은 제외한다.
- 절 끝 비고는 절별로 모아 선택 모델에 입력한다.

### 근거 확인 실패 조건

다음 경우 근거를 확인할 수 없는 것으로 처리한다.

- 전파법 제58조의2 제1항에 "적합성평가"가 없음
- 고시 별표 1에서 1-10절을 모두 찾지 못함
- 기기부호가 비었거나 중복됨
- 시행령 별표 6의2에서 개인 사용 반입 면제 목을 하나로 특정하지 못함

### 판단별 근거

선택한 행의 판단에는 고시 별표 1 행 원문, 전파법 제58조의2 해당 항, 시행령 별표 6의2 개인 사용 반입 면제 목을 첨부한다.

## 7. 실패·정보 부족

| 상황 | 처리 |
|---|---|
| 조건 추출·기자재 선택 모델 실패 | `RadioToolError` |
| 법제처 조회 자체의 실패 | `RadioToolError` |
| 근거 법령의 버전·본문을 확인할 수 없음 | 정보 부족, 가정에 기록 |
| 인용할 원문 없음 | 정보 부족 + 제품 종류·무선 기능 질문 |
| 무선 기능 없음 | 정보 부족 + 무선 기능 질문 (4.1) |
| 유사한 행 없음, 해당하는 행 없음 | 정보 부족, 가정에 기록 (3.1, 3.2) |

## 8. 상세 결과와 조회 기록

`RadioAssessment`:

| 칸 | 내용 |
|---|---|
| `wireless_features` | 원문과 대조된 무선 기능 값 |
| `frequency_bands` | 정규화한 주파수 대역 (예: "2400–2483.5 MHz") |
| `certification_type` | 선택한 행들의 평가유형 |
| `conformity_assessment_required` | 항상 `None` (후보만으로 확정하지 않음) |
| `legal_sources` | 비움. 근거는 판단에만 첨부 |

`query` 주요 키:

| 키 | 내용 |
|---|---|
| `search_terms` | 모델 조회어 |
| `frequency_bands` | 정규화한 주파수 대역 |
| `candidate_items`, `selected_items` | 후보 행, 선택한 행 |
| `assessment_types` | 선택한 행들의 평가유형 |
| `documents` | 근거 문서 버전 |
| `dropped_facts`, `dropped_candidates`, `not_applicable`, `over_limit` | 공용 대조 기록 ([TOOL_COMMON.md](TOOL_COMMON.md)) |

## 9. 설정

| 항목 | 값 |
|---|---|
| 후보 행 수 | 8 (`top_k`) |
| 선택 수 | 최대 3 (`SELECTIONS_LIMIT`) |
| 조회어 | 최대 3 |
| 절 비고 입력 길이 | 절마다 1500자 |
| 근거 캐시 | 기준일별 6시간 ([TOOL_COMMON.md](TOOL_COMMON.md) 7장) |
| 모델 프로필 | [TOOL_COMMON.md](TOOL_COMMON.md) 9장 |

모델 호출 단계의 사용량 이름은 `radio-facts`, `radio-review`다.
