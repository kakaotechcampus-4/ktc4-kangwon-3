# 전기용품 안전 Tool

전기용품 및 생활용품 안전관리 운용요령의 품목표에서 상품에 해당할 가능성이 있는 품목을 찾고, 제도(안전인증·안전확인·공급자적합성확인)와 판매 방식별 할 일을 제시하는 Tool이다. 실행 틀, 원문 대조, 질문, 법령 조회 등 공용 동작은 [TOOL_COMMON.md](TOOL_COMMON.md)에서 설명한다.

## 1. 개요

- 법령 원문 전체를 모델에 입력하지 않는다. 운용요령 별표 1-3 품목표에서 상품과 유사한 행 몇 개만 조회하고, 그중 해당하는 행을 모델이 선택한다.
- 판정은 `POSSIBLY_REQUIRED`(후보) 또는 `INSUFFICIENT_INFORMATION`(정보 부족)만 사용한다. 확정 판정(`REQUIRED`·`NOT_REQUIRED`)은 생성하지 않는다.
- 품목 분류 자체가 후보이므로 모든 안내는 "이 품목으로 분류되면 …" 형식의 조건부로 작성한다.
- 판매 방식(구매대행·사입)은 상품 정보로 알 수 없으므로 두 경우의 할 일을 함께 제시한다.

| 역할 | 담당 |
|---|---|
| 상품 조건 값과 원문 인용 추출 | 모델 |
| 인용 대조, 누락·충돌 판정, 저전압 판정, 품목 조회, 근거 첨부 | 코드 |
| 후보 행 중 상품에 해당하는 행 선택과 선택 이유 | 모델 |

## 2. 입력

### 조건 필드

| 필드 | 표시 이름 | 질문 여부 |
|---|---|---|
| `product_type` | 제품 종류 | 항상 질문 (확인되지 않으면 조회하지 않음) |
| `power_source` | 전원 방식 | 질문 (5장의 생략 규칙 적용) |
| `rated_voltage` | 정격 전압 | 질문 (5장의 생략 규칙 적용) |
| `battery_only` | 전지로만 동작(코드나 어댑터 없이) | 조건부 질문 |
| `intended_use` | 제품 용도 | 질문하지 않음 |
| `adapter_included` | 어댑터 포함 여부 | 질문하지 않음 |
| `rated_power` | 정격 소비전력 | 질문하지 않음 |

- `battery_only`는 값이 판단 결과("예"·"아니오")이므로 인용만 원문과 대조한다.
- 조건 추출 모델은 품목표 조회용 일반 명칭(`search_terms`, 최대 3개)을 함께 출력한다. 조회어는 판단 근거가 아니므로 원문 대조 대상에서 제외한다.
- 모델 힌트에 속성 이름과 값을 포함한다(`hints_with_attributes`).
- 인용할 원문이 없으면 제품 종류, 전원 방식, 정격 전압을 질문한다.
- 전원 방식·정격 전압이 확인되지 않아도 품목 검토는 계속하고, 해당 조건은 질문으로 기록한다.

## 3. 처리 흐름

```text
① 조건 추출 (모델)   제품 종류·전원·전압 등 + 원문 인용, 조회어
② 품목 조회 (코드)   운용요령 별표 1-3 품목 행 중 유사한 상위 8개
③ 코드 규칙          저전압 판정, 전기저장장치 구성품 행 제외, 전지 전용 구조 처리
④ 품목 선택 (모델)   후보 행 중 해당하는 행 최대 3개 + 선택 이유
⑤ 결과 조립 (코드)   행 원문 근거, 구매대행 특례 대조, 판매 방식별 할 일
```

### 3.1 품목 조회

- 조회어는 모델 조회어, 제품 종류·제품 용도·전원 방식 값, 상품명·카테고리·용도를 합하여 구성한다.
- 순위는 품목·세부품목 이름과 조회어의 글자 2개 단위 유사도로 산정하며, 세부품목 이름이 조회어에 그대로 포함되면 가산한다(`common.ranking.rank_rows`).
- 상품별 동의어 사전은 사용하지 않는다. 상품명을 품목표의 일반 명칭으로 바꾸는 일은 조건 추출 모델의 조회어가 담당한다.
- 근거 문서는 시행규칙 제3조, 운용요령 제3조, 운용요령 별표 1-3, 시행규칙 별표 13이다. 기준일별로 캐시한다([TOOL_COMMON.md](TOOL_COMMON.md) 7장).
- 근거 문서를 확인할 수 없으면 "법령 품목표의 시행 버전·본문을 확인하지 못해 품목을 대조하지 않았습니다." 가정을 기록하고 정보 부족으로 종료한다.

### 3.2 전기저장장치 구성품 행 제외

법령 제외 규칙이 아니라 오답을 줄이기 위한 후보 필터다.

- 분류명에 "전기저장장치"가 포함된 행은, 원문과 대조된 조건의 값·인용에 전기저장장치·에너지저장장치·ESS·전지시스템 중 하나가 없으면 후보에서 제외한다.
- 제외한 행은 `query.filtered_items`에 기록한다.
- 원문에 용도가 기재되지 않은 실제 전기저장장치 부품은 후보에서 누락될 수 있다.

### 3.3 전지 전용 구조

운용요령 별표 1-3 끝의 공통 비고에 따라, 1차·2차 전지만을 전원으로 사용하는 구조는 각 제도의 대상에서 제외된다.

- `battery_only` 값이 모두 "예"이면 전지 전용, 모두 "아니오"이면 전지 전용이 아닌 것으로 판단한다. 그 밖의 경우는 판단하지 않는다.
- 전지 전용이면 본체 행을 제외하고 전지·충전기·직류전원장치·어댑터·전격살충기 행만 유지한다(`query.battery_only_excluded`).
- 이어서 "충전지 전지", "전지 충전기", "직류전원장치"로 추가 조회하여 전지·충전기 행(전기저장장치 구성품 제외)을 후보에 추가한다. 추가 조회가 실패하면 `ElectricalToolError`로 처리한다.
- 공통 비고는 선택 모델 입력에도 포함한다.

## 4. 판정 규칙

### 4.1 저전압 제외

운용요령 제3조에 따라 교류 30V·직류 42V 이하 제품은 대상에서 제외된다. 단, 행 비고에 저전압 제품도 포함한다고 정한 행은 예외다.

- 기재된 전압이 모두 기준 이하이면 저전압, 모두 기준을 초과하면 저전압 아님으로 판정한다.
- 교류와 직류가 함께 기재되었거나 전류 종류를 확인할 수 없는 경우, 또는 기재된 전압이 기준 이하와 기준 초과에 모두 해당하는 경우에는 판정하지 않는다.
- 저전압이면 저전압 포함 비고가 없는 행은 선택할 수 없다. 모델이 선택하면 코드가 제외한다(`dropped_candidates`).
- 전원·전압이 충돌하면 저전압 판정을 하지 않는다.

### 4.2 전원·전압 충돌

전원 방식과 정격 전압은 글자가 아니라 의미로 비교한다(`rules.power_conflicts`). 표기만 다르고 저전압 판정이 같으면 충돌로 보지 않는다.

| 원문 값 | 처리 |
|---|---|
| `USB`와 `DC`, `USB-C 입력`과 `DC` | 모두 직류. 충돌 아님 |
| `0~5V`와 `5V`, `AC 100-240V` | 범위는 V가 표기된 끝값(최댓값)으로 판단. 충돌 아님 |
| `220V`와 `110V` (교류) | 모두 기준 초과로 판정이 같음. 충돌 아님 |
| `AC 220V`와 `DC 12V` | 교류·직류 혼재. 충돌 |
| `24V`와 `220V` (교류) | 기준 이하와 기준 초과에 모두 해당. 충돌 |

- 충돌로 판정하는 조건은 판단에 영향을 주는 전원·전압과 전지 전용 여부("예"·"아니오"가 함께 확인된 경우)뿐이다.
- 제품 종류·용도는 값이 여러 개여도 모두 조회어로 사용한다. 정격 소비전력·어댑터 포함 여부는 판단에 사용하지 않으므로 충돌을 검사하지 않는다.
- 충돌한 조건이 있으면 "상품 정보에 모순이 있어 해당 조건(…)은 판정하지 않았습니다." 가정을 기록하고 확인 질문을 생성한다.
- 상품 본체와 동봉 부속품(어댑터·전지)의 조건은 구분하지 않는다. 본체 DC 12V와 어댑터 AC 220V가 함께 기재되면 충돌로 판정한다.

### 4.3 구매대행 특례

선택한 행의 품목명을 시행규칙 별표 13(구매대행 특례 제품) 목록과 대조한다(`evidence.purchase_agent_status`).

| 상태 | 의미 |
|---|---|
| `listed` | 별표 13에 품목명이 있음 |
| `listed_with_exclusion` | 품목명이 있으나 뒤에 "…는 제외" 조건이 있음 |
| `unmatched` | 품목명을 찾지 못함. 표현 차이일 수 있으므로 "특례 없음"으로 판정하지 않음 |
| `similar_clause` | 품목표의 "그 밖에 … 유사한 기기" 행 |
| `unknown` | 별표 13을 확인하지 못했거나 해당 제도의 특례 목록이 없음 |

- 대조 시 별표 13에서 "대상 없음" 줄은 제외한다.
- 쉼표로 묶인 품목명은 앞부분으로도 대조하며, 3자 이상인 이름만 사용한다.
- 결과는 `query.purchase_agent`에 행별로 기록한다.

### 4.4 선택 대조

선택은 공용 후보 선택 대조를 거친다([TOOL_COMMON.md](TOOL_COMMON.md) 5장). 이 Tool은 선택 수 상한을 모델 출력 형식(최대 3개)으로 제한하며, 저전압 제외 대상 행은 코드 규칙으로 제외한다.

## 5. 화면 문구

### 판단

| 경우 | 제목 | 요약 |
|---|---|---|
| 선택한 행 | {제도}대상 후보 — {품목} | "이 품목으로 분류되면 {제도}대상 전기용품일 가능성이 있습니다(확정 아님)." + 구매대행 상태 문장 |
| 정보 부족 | 전기용품 안전관리 대상 판정 | 아래 표 |

- 선택한 행의 위험도는 `MEDIUM`이고, 판단 근거는 선택 모델이 작성한 선택 이유다.
- 품목명은 번호를 제거하고, "…만해당한다)"는 "…만 해당)"으로, "(신 설)"은 제거하여 표시한다. 근거 인용은 원문을 그대로 사용한다.
- 모든 후보 판단에 "LLM 품목 선택이며 규제 적용·인증 보유를 확정하지 않았습니다." 가정을 기록한다.
- 선택 모델이 추가로 필요하다고 표시한 조건 중 질문 대상이 아닌 조건(용도·소비전력 등)은 "품목 확정에는 … 확인이 더 필요합니다." 가정으로 기록한다.

정보 부족 판단의 요약은 보류 사유(`query.undecided`)에 따라 다음 순서로 결정한다.

| 조건 | 요약 |
|---|---|
| 전지 전용이라 본체 행을 제외함 | "건전지나 충전지로만 동작하는 제품이라 본체는 전기용품 안전관리 대상에서 빠질 수 있습니다. 내장 전지나 충전기가 대상인지는 판단하지 못했습니다." |
| 저전압이라 후보 행이 모두 제외됨 (`low_voltage`) | "정격 전압(…)이 저전압(교류 30V·직류 42V 이하)이라 비슷한 품목이 모두 전기용품 안전관리 대상에서 빠지는 범위입니다. …" |
| 전원·전압을 확인했으나 해당 행이 없음 (`low_voltage`, `no_match`, `no_rows`) | "상품 설명에서 전원 방식(…)·정격 전압(…)을 확인했지만 해당하는 전기용품 품목을 찾지 못해 대상인지 판단하지 못했습니다." |
| 그 밖의 경우 | "상품 설명에서 전원 방식·정격 전압 같은 전기 정보나 해당하는 품목을 찾지 못해 전기용품 안전관리 대상인지 판단하지 못했습니다." |

### 할 일

선택한 행마다 판매 방식별 할 일을 생성한다. 머리말은 "[{품목} · {제도} 후보]"이며, 제도별 확인 명칭은 안전인증은 "KC 안전인증", 안전확인은 "KC 안전확인 신고", 공급자적합성확인은 "공급자적합성확인"이다.

| 구매대행 상태 | 구매대행 | 사입·수입 |
|---|---|---|
| `listed` | 특례 대상이므로 KC 표시 없이 구매대행 가능. 구매대행업자의 고지 의무(법 제36조) 안내 | KC 인증·신고 번호 확인 |
| `listed_with_exclusion` | 제외 조건에 해당하지 않으면 특례 적용 가능. 제외 조건 해당 여부 우선 확인 | KC 인증·신고 번호 확인 |
| `unmatched` | 특례 해당 여부 확인 전까지 KC 받은 제품만 판매 권장 | KC 인증·신고 번호 확인 |
| `similar_clause` | "그 밖에 유사한 기기" 해당 여부 확인 필요 (한 건으로 함께 안내) | |
| `unknown` (공급자적합성확인) | 의무 확인 필요 (한 건으로 함께 안내) | 공급자적합성확인과 KC 표시 필요 |
| `unknown` (그 밖의 제도) | 판매 전 해당 KC 확인 (한 건) | |

판단마다 해당 행의 할 일을 `requirements`에 저장한다. 재실행에서 판단이 제외되면 Tool 실행기가 해당 할 일만 삭제한다.

### 질문

질문 대상은 제품 종류, 전원 방식, 정격 전압, 전지 전용 여부다. 질문은 판단에 영향을 주는 조건에만 생성한다.

**전지 전용 여부 질문**

- 전지 전용 여부를 판단하지 못했고 상품에 전지 언급(전원 방식·제품 종류의 충전·배터리·전지·건전지·무선·코드리스, 또는 `battery_included`)이 있으면, 본체 행 판단마다 질문을 생성한다.
- 이때 "전지(건전지·충전지)만으로 동작하는 구조라면 본체는 {제도}대상에서 제외됩니다(운용요령 별표 공통 비고)." 가정과 공통 비고 근거를 첨부한다.

**선택한 행이 있을 때의 질문 생략** (`_question_skips`)

| 생략 사유 | 조건 | 가정 |
|---|---|---|
| 답변이 판단을 바꾸지 않음 | 선택한 행이 모두 교류·직류 저전압 포함 비고가 있는 행이면 전원 방식·정격 전압 생략 | "… 어떤 답이든 고른 품목 행의 판단이 같아 묻지 않았습니다." |
| 답변이 판단을 바꾸지 않음 | 선택한 행이 모두 전지·충전기 행이면 전지 전용 여부 생략 | 위와 같음 |
| 질문 정책 | 본체 행이 있으나 전지 전용 여부 조건이 추출되지 않았고 판매 글·속성 원문에도 전지·충전 언급이 없으면 전지 전용 여부 생략 | "상품 원문에 전지·충전 언급이 없어 전지로만 동작하는지는 묻지 않았습니다. 전지로만 동작하지 않는다고 확인한 것은 아닙니다." |

- 충돌 확인 질문도 "답변이 판단을 바꾸지 않음" 사유에 해당하면 생략한다. 충돌 사실은 가정에 그대로 남는다.
- 생략한 질문 필드는 "품목 확정에는 … 확인이 더 필요합니다." 가정에 다시 포함하지 않는다.
- 선택한 행이 없으면 생략 규칙을 적용하지 않는다.

**그 밖의 규칙**

- 전원 방식과 전지 전용 여부를 같은 회차에 함께 질문하지 않는다. 전원 방식을 먼저 질문하고, 전지 전용 여부는 다음 회차에 질문한다. 단, 이전 회차에 전원 방식을 이미 질문했거나 둘 중 하나가 충돌 확인 질문이면 함께 질문한다.
- 해당하는 행이 없고 전기 관련 조건(전원 방식·정격 전압·정격 소비전력·전지 전용 여부·어댑터 포함 여부)도 확인되지 않으면, 전원·전압을 질문하지 않고 "상품 원문에 전기 관련 조건이 없어 전원·전압을 묻지 않았습니다." 가정을 기록한다.

## 6. 근거

| 근거 | 첨부 조건 |
|---|---|
| 선택한 행 원문 (분류·품목·세부품목·비고) | 항상 |
| 운용요령 제3조 | 저전압으로 판정한 경우 |
| 운용요령 별표 공통 비고 | 전지 언급이 있고 본체 행인 경우 |
| 시행규칙 별표 13 해당 제도 부분 | 구매대행 상태가 `unknown`이 아닌 경우 |

- 근거 출처 이름은 "법제처 국가법령정보"이며, URL은 버전을 고정한 공개 열람 주소다.
- 시행규칙 제3조와 운용요령 제3조에 판단에 사용하는 문구(1천볼트, 별표 3-5, 30V 이하, 42V 이하 등)가 없거나 별표에서 세부품목을 찾지 못하면 근거를 확인할 수 없는 것으로 처리한다.

## 7. 실패·정보 부족

| 상황 | 처리 |
|---|---|

| 해당하는 행 없음 (`no_match`, `low_voltage`) | 정보 부족. "후보 행 중 상품에 맞는 품목을 고르지 못했습니다. 비대상 판단이 아닙니다." |

| `documents` | 근거 문서 버전 |
